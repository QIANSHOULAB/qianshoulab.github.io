# 化缘僧 0.4.1 · 上架 Chrome 应用商店，照着点

全在电脑上的 Chrome 里做。文件都在这个文件夹（仓库 `huayuan/store/`）。英文按钮照后台原样写，括号里是中文意思。要贴的字在 `listing-en.md`、`listing-zh.md`、`privacy.md` 的 ``` 框里，整段复制。

## 0. 先进后台

1. 打开 https://chrome.google.com/webstore/devconsole ，用 lunzigeju@gmail.com 登录。
2. 第一次进，后台要是先要你办账户的事（左边 **Account**（账户）页：联系邮箱点 **Verify**（验证）去邮箱点链接；欧盟要求的 trader / non-trader（商家 / 非商家）声明），照提示办完再往下。这一步只有你能做。

## 1. 传 zip

1. 右上角 **New item**（新建项目）。
2. 把 `huayuan-0.4.1.zip` 拖进去（或点 **Browse files**（选文件）选它）。不用解压。
3. 传完自己跳到这个插件的页面，左边一列是 Package / Store listing / Privacy / Distribution……下面照这个顺序填。

## 2. Store listing（商店页，英文）

照 `listing-en.md`：

1. **Description**（详细说明）：贴英文那段。
2. **Category**（类别）：选 **Tools**（工具）。
3. **Language**（语言）：选 **English**。
4. **Store icon**（商店图标）：拖 `icon-128.png`。
5. **Screenshots**（截图）：按顺序拖 `screenshots-en/` 里 1、2、3、4 四张。
6. **Small promo tile**（小宣传图）：拖 `promo-440x280.png`。Marquee promo tile（大横幅）、YouTube video 空着。
7. **Official URL** 不选；**Homepage URL**（主页）、**Support URL**（支持网址）都填 `https://qianshoulab.github.io/huayuan/`；**Mature content**（成人内容）关着。
8. 右上角 **Save draft**（存草稿）。

## 3. 中文商店页

1. 还在 Store listing，顶上的语言下拉换成 **Chinese (China)**（中文）。
2. **Description**：贴 `listing-zh.md` 的中文那段。
3. **Localized screenshots**（这个语言的截图）：按顺序拖 `screenshots-zh/` 里 1、2、3、4。
4. **Save draft**。

## 4. Privacy（隐私权）

照 `privacy.md`，从上到下：

1. **Single purpose description**（单一用途）：贴那一句。
2. 五个 **justification**（为什么要这个权限）框：activeTab、scripting、storage、sidePanel、Host permission，各贴各的那段。
3. **Remote code**（远程代码）：选 **No, I am not using remote code**（没有）。
4. **Data usage**（数据使用）第一组：只勾 **Website content**（网站内容），别的都不勾。为什么勾这一个见 privacy.md 那张表。
5. 第二组三个保证：**三个全勾**。
6. **Privacy policy URL**（隐私政策网址）：`https://qianshoulab.github.io/privacy/`
7. **Save draft**。

## 5. Distribution（发布范围）

1. 有 **Payments**（收费）这一栏就选 **Free of charge**（免费）；没有就跳过。
2. **Visibility**（谁能看到）：**Public**（公开）。
3. **Distribution regions** / Geographic distribution（地区）：**All regions**（所有地区）。
4. **Save draft**。

## 6. Test instructions（给审核员的测试说明；后台有这一页才填）

不用账号，贴这段：

```
No account needed.
1. Open https://qianshoulab.github.io/huayuan/demo/table.html
2. Click the Huayuan toolbar icon (or press Alt+Shift+H). The side panel opens with the client list it found: 20 rows.
3. Click Start. It goes through all 5 pages and downloads an .xlsx with 100 rows. If Chrome drops access after a page reload, the panel shows an "Allow" button: click it once.
More sample pages (cards, infinite scroll): https://qianshoulab.github.io/huayuan/demo/
```

**Save draft**。

## 7. 提交

1. 右上角 **Submit for review**（提交审核）。
2. 弹出的框里有一个勾 **Publish automatically after review**（审过自动上架，后台字可能略有不同）：勾着 = 审过直接上架；不勾 = 审过后你自己再点 **Publish**（发布）。
3. 点框里的 **Submit for review**。完事。审核一般几天，结果发到 lunzigeju@gmail.com。
