## 关键做法

- **无状态注入**：面板每次用 `chrome.scripting.executeScript` 调 `globalThis.Huayuan[method]`，发现脚本没了（页面整页跳转）就重新注入再调。面板把「目标」`{path, sig}` 传过去，网页那边每次重新定位，所以整页跳转、Ajax 重绘都不怕。
- **猜名单**：每个父元素里按「标签名+去掉状态类后的 class」分组，取最大组（≥3 个、可见）。分数 = 子元素总面积 × log(个数) × 文字量系数 × 字段丰富度；在 nav/header/footer/aside 里 ×0.12，纯单链接菜单 ×0.35。前 8 个当候选，「换一块」轮换。
- **字段键**：行内结构路径（tag.第一个有效 class，同名兄弟加 #n）+ `|t`/`|href`/`|src`。只含行内标签的元素整块取文字。列顺序跟页面一致（新字段插到同一行里前一个字段后面）。
- **列名**：表头（th）> 中文 class/属性提示 > 英文 class 映射表（strings.js 的 hintWords；原价在价格前面判）> h1–h6 当「名称」、del/s 和 line-through 样式当「原价」 > 按值猜（邮箱/网址/日期/价格/电话）> 英文 class 原样 > 字段N。「电话：」这种：值里统一前缀 → 去掉前缀当列名；单独一列恒为「xx：」→ 当下一列的名字并收起。恒定值的列（如「编辑」按钮）、和别的列一模一样的列、填充 <5% 的列自动收起，「放出来」可恢复。
- **去重**：整行所有字段拼成签名。滚动加载 / 加载更多时旧行仍在页面上，不算重复（判断：这一批第一行已经见过 = 追加式）。
- **翻页循环**（panel.js run）：记指纹（url + 行数 + 首尾行文字哈希 + 页面高度 + 网络安静了多久 + 有没有「到底了 / 加载中」告示）→ 点下一页 / 滚到底 → 每 100 毫秒看一次，指纹变且连续两次一样 → 等网络安静 300 毫秒（最多 2 秒）→ 整页换内容的再多等「每页多等几秒」（默认 0.3）；追加式（行数变多：加载更多 / 无限滚动）不多等，晚到的下一轮照样收 → 收。收工时统一补等一次「多等几秒」再收一遍。下一页找不到/禁用、连续 3 次没新行、到最多页数、用户点停或按 Esc 就收工。
- **滚动收尾**：页面上看得见「到底了 / 没有更多 / no more」（不在名单里、40 字以内）就立刻收；名单没动、页面没长、网络安静、没有「加载中」超过 3 秒也收。页面在长但名单没动（虚拟列表）才再滚两次。
- **试滚**（panel.js trialStart/trial）：没下一页、页面能滚的，打开时先替用户滚到底（跟画表同时进行），看 0.45 秒（有「加载中」最多 6 秒）。表一出来导出键就能点，不用等试滚。下结论「整页」后再盯 5 秒（lateWatch），名单自己长了就改成「滚动」接着滚完。出新货 = 无限滚动，直接接着滚完（不用点开始）；没出 = 回原位、选「只这页」、写「整页都在这了」。面板准备好后 body 上挂 data-ready，测试和跑分等它。
- **网络安静**：content 脚本注入时挂 PerformanceObserver（type resource, buffered）记最后一个 responseEnd；不用 getEntries，因为资源缓冲满 250 条后不再记。图片、样式、字体（initiatorType img/css/link/font…）不算：懒加载图片一滚一串，只会白等。
- **列顺序**：没拖过时，文字列在前（页面顺序），链接列其次，图片列最后。
- **值清洗**：「电话：」冒号前缀，和「评分 4.0」这种中文标签 + 空格 + 纯数字，80% 的值都有同一个前缀就拆成列名。mailto:/tel: 链接列去掉前缀后跟别的列一样就收起。
- **xlsx**：纯数字写数字；带小数的给 0.0 / 0.00… 格式保住小数位；表头像编号/电话/ID/SKU/code 的列一律写文字。
- **权限**：只靠 activeTab。整页跳转后若浏览器收回临时授权，executeScript 报权限错 → 面板弹「允许这个网站」按钮（chrome.permissions.request 只要那一个站），用户点了接着化。
- **下载文件名用中文**（化缘_域名_时间.xlsx，前缀在 strings.js 的 filePrefix）。0.1.0 时以为 Chromium 不认中文 `a.download`，其实是沙盒 LANG 为空（C 语言环境），Chromium 转不了文件系统编码就退成 `download`；`LANG=C.UTF-8` 下正常。测试和跑分都要带 LANG=C.UTF-8。

## 0.3.0：去掉没必要的步骤（2026-11-03）

- **人只做两件事**：扫一眼认得对不对（拿不准的标黄），决定翻不翻全部页（点「开始」）。
- **化完自己下**（panel.js run 收尾）：人点过「开始」（或者这一块上回在这个网站下过），化完 `ended === 'end'`、设置「化完自己下载」开着、`doubts().n === 0`，就按上回用的格式直接下，状态写「化完了，已下载」，下面一行「化完自己下好了 · 以后别自己下」（点了就关掉设置）。停了、到上限、有标黄，都不自己下，等人点。
- **标黄（doubts）**：①列名只能叫「字段N」或照抄英文 class（sheet.js 的 `weak`；用户改了名就不黄）；②还有一块分数到第一块的六成（`AMBIGUOUS = 0.6`，用户换过 / 上回认过就不算）；③翻到「最多翻几页」上限才停。单页没有「开始」，人看一眼点「下载 Excel」就是那一下确认。
- **记性（按网站）**：`chrome.storage.local` 的 `site:<host>` = `{ list: [...] }`，最多 8 条、最近的在前，每条 `{ block:{path,sig}, prefs:{user,order}, next, ok, run }`。改名 / 删列 / 拖序 / 放出来 / 换一块 / 指下一页 / 下载时写。打开时 recall()：下载过的优先，先找路径 + 行长相一样的块，再找「长相一样、这页只有一块长这样」的。认上了就照办：列名删列顺序、下一页、哪一块；上回翻完全部页再下的（run === 'next'），这回自己开翻。办了啥写在表下面「照上次的改法：改名 1、删 1 列、调了顺序、自己开翻 · 还原」，「还原」= 回到自己猜的样子 + 把这条记性删掉。
- **一屏一个主按钮**：「开始」亮着时下载是灰的；下载按钮的主次跟着上回用的格式（Excel / CSV）走。
- **出错放在出事的地方**：网页关了 → 表还在，上面一条「网页关了，已收的 N 行还在，照样能下」，下载照常。空状态 → 一句话 +「用示例试试」（侧栏里直接摆示例表，也能下）+「去示例网页化一回」。
- 步骤账、复赛数字见 bench/比武报告.md「0.3.0 复赛」。

## 0.4.0：中英两套（2026-11-03）

- **默认英文，第二语言中文**（Song 11-03 22:19）。侧栏右上角 EN / 中文 分段控件，点了存 chrome.storage.local 的 lang，下回打开直接是上次选的；不跟浏览器 / 系统语言自动切。介绍页同样默认英文、右上角切换（localStorage 的 huayuan.lang），网址带 ?lang=zh|en 先听网址。
- **字全在 extension/lib/strings.js**。介绍页也读这个文件（<script src="extension/lib/strings.js">），静态 HTML 只留英文 <title> 和 meta description（给链接预览用），别的字全由脚本填；<html lang>、<title>、description 跟着换。介绍页的图分中英两套：img/side-*.jpg（中文）、img/side-*-en.jpg（英文），由 bench/intro-img.py 从 e2e 的 duo 截图出。
- **商店文案**用 _locales（en、zh_CN），default_locale = en：浏览器是中文就显示中文名「化缘僧 · 过路留名，见网扒皮」，别的语言都是 Huayuan · List Grabber。这一处跟浏览器语言走，侧栏的切换管不到（浏览器的规矩）。
- **换语言时**：静态字、按钮、状态、照上次办了啥（存键不存字）、空状态、网页关了的提示、示例表全换；插件自己起的列名跟着换（sheet.relabel），人改过的列名不动。
- **列名**：hintWords 的值从中文名改成键（colCompany…），按当前语言出字；「字段N」「名称链接」「名称2」也走模板（colFieldN / colLinkOf / colDup），中文结果跟 0.3.0 一字不差。
- **英文表头也照用**（修了个英文才露出来的毛病）：0.3.0 只把中文表头直接当列名，英文表头被当成 class 词去猜——Stage 猜成「标签」、整排标黄、于是也不自己下。现在 content 脚本把表头来的名字记成 head，哪种语言的表头都直接用、不标黄。中文测试站结果不变。
- **到底了**的英文告示认弯引号（you’ve reached the end、that’s all）。
- **导出文件名**：中文「化缘_域名_时间.xlsx」，英文「Huayuan_域名_时间.xlsx」；示例表是「化缘_示例_…」「Huayuan_Sample_…」。
- **测试和跑分认状态不看字**：body 上 data-state（running / trying / end / stop / max / idle）、data-dl（自己下好了 = 1）。老版本没有，脚本退回看中文状态字。
- 示例站也是中英两套：英文表头 ID / Company / Contact / Phone / Email / City / Stage / Created，卡片「Phone: …」，滚动页「Loading…」「No more items」。

## 踩过的坑

- Playwright 默认 headless 等不到 service worker → 用 `channel: 'chromium'`。
- `chrome.windows.create` 给的 left/top 超出屏幕会直接报错（多显示器常见）→ 失败就不带位置再开一次。
- 介绍页 `<img width height>` 再配 `width:%` 必须加 `height:auto`，不然图被压扁。
- `.w{margin:0 auto;padding:0 16px}` 会盖掉 `section{padding/margin}`（类选择器优先级更高）→ 写 `section.w{...}`。
- 示例站头像用 data: SVG 时，图片列全是一长串 base64 → 抓取时丢掉 data: 图（先看 data-src 等懒加载属性），示例站改用真 svg 文件。
- 快捷键 Alt+Shift+H（_execute_action）在 Playwright（含 xvfb 有头）里按不出来，activeTab 的真实授权流程没法自动测，只能人工点一遍。
