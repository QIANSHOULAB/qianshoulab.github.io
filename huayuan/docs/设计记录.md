# 化缘僧 · 设计记录（给接手的 Claude 看）

扒名单：用户在任何网页上点一下插件，把列表 / 表格抓成一张表，导出 xlsx / csv。对标 Instant Data Scraper、Browse AI。
线上：https://qianshoulab.github.io/huayuan/ ；示例站（也是测试站）：/huayuan/demo/

## 结构

```
huayuan/
  index.html              介绍页（单文件，截图在 img/）
  demo/                   示例站 = 测试站：table.html（表格，?p= 整页跳转 5 页）、cards.html（卡片，Ajax 翻 4 页）、scroll.html（无限滚动 120 件）。data.js 是随机拼的假数据
  dist/huayuan-0.1.0.zip  打好的包（manifest 在 zip 根目录，Edge 商店要求）
  extension/              插件源码（Manifest V3）
    manifest.json         权限只有 activeTab / scripting / storage；optional_host_permissions 备用
    background.js         点图标 → 开一个 popup 小窗 panel.html?tab=ID（一个标签页只开一个）
    panel.html/css/js     面板 = 大脑：数据、列操作、翻页循环都在这里
    content/huayuan.js    化缘僧业务（注入网页）：猜名单 scan、拆字段 extract、找下一页、点下一页、滚动加载、点选下一页
    lib/                  ★ 通用模块，巡山僧 / 代笔僧将来共用，别把化缘僧业务写进去
      strings.js          所有界面文字（QSStrings.t），加英文就加一个 en 块
      page.js             读网页：可见性、CSS 路径、文字块、高亮标记、点选元素（QSPage）
      sheet.js            表的数据模型：收行、去重、自动列名、自动收起没用的列、改名/删列/拖序（QSSheet）
      export.js           xlsx（手写 OOXML + 不压缩 zip，零依赖）、csv（带 BOM、防公式注入）、复制 TSV（QSExport）
      settings.js         chrome.storage.local 包一层（QSSettings）
      ui.css              颜色 token（跟随系统深浅色）、按钮、分段控件、toast、页脚
  test/e2e.js             端到端测试
```

## 关键做法

- **无状态注入**：面板每次用 `chrome.scripting.executeScript` 调 `globalThis.Huayuan[method]`，发现脚本没了（页面整页跳转）就重新注入再调。面板把「目标」`{path, sig}` 传过去，网页那边每次重新定位，所以整页跳转、Ajax 重绘都不怕。
- **猜名单**：每个父元素里按「标签名+去掉状态类后的 class」分组，取最大组（≥3 个、可见）。分数 = 子元素总面积 × log(个数) × 文字量系数 × 字段丰富度；在 nav/header/footer/aside 里 ×0.12，纯单链接菜单 ×0.35。前 8 个当候选，「换一块」轮换。
- **字段键**：行内结构路径（tag.第一个有效 class，同名兄弟加 #n）+ `|t`/`|href`/`|src`。只含行内标签的元素整块取文字。列顺序跟页面一致（新字段插到同一行里前一个字段后面）。
- **列名**：表头（th）> 中文 class/属性提示 > 英文 class 映射表（strings.js 的 hintWords）> 按值猜（邮箱/网址/日期/价格/电话）> 英文 class 原样 > 字段N。「电话：」这种：值里统一前缀 → 去掉前缀当列名；单独一列恒为「xx：」→ 当下一列的名字并收起。恒定值的列（如「编辑」按钮）、和别的列一模一样的列、填充 <5% 的列自动收起，「放出来」可恢复。
- **去重**：整行所有字段拼成签名。滚动加载 / 加载更多时旧行仍在页面上，不算重复（判断：这一批第一行已经见过 = 追加式）。
- **翻页循环**（panel.js run）：记指纹（url + 行数 + 首尾行文字哈希）→ 点下一页 / 滚到底 → 轮询到指纹变且连续两次一样 → 等「每页等几秒」→ 收。连续 3 次没新行、下一页找不到/禁用、到最多页数、用户点停或按 Esc 就收工。
- **权限**：只靠 activeTab。整页跳转后若浏览器收回临时授权，executeScript 报权限错 → 面板弹「允许这个网站」按钮（chrome.permissions.request 只要那一个站），用户点了接着化。
- **下载文件名用英文**（huayuan_域名_时间.xlsx）：Chromium 下 blob 下载用中文 `a.download` 时，Playwright 里拿到的名字变成 `download`，为了稳妥用 ASCII。

## 怎么测

```
cd 仓库根目录
PW_CHANNEL=chromium node huayuan/test/e2e.js /tmp/huayuan-shots
```

- 必须 `channel: 'chromium'`（新 headless），老 headless 不加载扩展。
- 自己起静态服务（127.0.0.1:8765）挂 huayuan/ 目录；复制一份插件，manifest 里加 `host_permissions: ["http://127.0.0.1/*"]` 当测试版（Playwright 点不了工具栏图标，拿不到 activeTab）。正式包不带这个。
- 从 service worker 调 `openPanel(tab)`（跟点图标同一个函数）开面板小窗。
- 覆盖：表格整页翻 5 页 100 行；删列/改名/拖列后导出 xlsx（openpyxl 读回核对）、csv（BOM、行数）；去重；卡片 Ajax 翻 4 页 48 条、「电话：」前缀拆列；无限滚动 120 件、xlsx；换一块；手动点选下一页、中途停；关面板清高亮；chrome:// 页面给示例。全程收集 pageerror / console.error，非零就失败。
- 截图（浅色/深色、面板/网页高亮）写到参数目录，介绍页的图就是从这里转 jpg 来的。

## 踩过的坑

- Playwright 默认 headless 等不到 service worker → 用 `channel: 'chromium'`。
- `chrome.windows.create` 给的 left/top 超出屏幕会直接报错（多显示器常见）→ 失败就不带位置再开一次。
- 介绍页 `<img width height>` 再配 `width:%` 必须加 `height:auto`，不然图被压扁。
- `.w{margin:0 auto;padding:0 16px}` 会盖掉 `section{padding/margin}`（类选择器优先级更高）→ 写 `section.w{...}`。
- 示例站头像用 data: SVG 时，图片列全是一长串 base64 → 抓取时丢掉 data: 图（先看 data-src 等懒加载属性），示例站改用真 svg 文件。
- 快捷键 Alt+Shift+H（_execute_action）在 Playwright（含 xvfb 有头）里按不出来，activeTab 的真实授权流程没法自动测，只能人工点一遍。
