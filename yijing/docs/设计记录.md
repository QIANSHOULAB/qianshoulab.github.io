# 译经僧 · 设计记录（给接手的 Claude）

网址：https://qianshoulab.github.io/yijing/ 　版本：0.1.0（开荒毛坯，2026-11-03）

## 干什么
把 A 系统导出的文件（CSV / TSV / XLSX / JSON）翻成 B 系统导入模板的格式。只做文件翻译，不连系统。全在浏览器本地跑。

## 结构
- `index.html`：单文件，CSS + 全部 JS。顶部 `STR` 对象是全部界面文字（加英文就复制一份 STR 换掉）。
- `lib/xlsx.full.min.js`：SheetJS 0.18.5（npm 包原样拷贝，Apache-2.0，见 `lib/xlsx.LICENSE`），只在读写 Excel 时懒加载。
- JS 分区（按 index.html 里的注释块）：
  - 概念词典 `C`：每个概念一组列名同义词（中英），带目标类型 t。`VS`：选项值同义词（男/女→M/F、在售→active、资产→Asset、借/贷…）。
  - 内置模板 `TPL`：6 个（CRM 英文、客户名单中文、Shopify 常用列、网店中文、会计科目中/英）。列可带 c（指定概念）、t（类型）、v（选项）、fmt、dec、req。
  - 读文件 `readFile`：编码自动（UTF-8 失败退 GB18030，认 BOM/UTF-16），分隔符嗅探，跳过表头上方的标题行，JSON 自动找数组并把嵌套对象拍平成 `a.b`。
  - 转换 `compile(map, targetCol)`：把一列的配置编成 `row => string`，出错置全局 `BAD`。之后按目标类型验货（邮箱、选项值、必填）。
  - 自动对列 `autoMap`：评分——规整后同名 100；同概念且同义词完全一样 92（对上）；列名里含同义词 72（存疑）；bigram 模糊 ≥60（存疑）；列名不像但内容像（邮箱/电话/日期）58（存疑）。贪心一对一。另有特例：拆姓名（First/Last ← 姓名）、合姓名、Shopify Handle 借货号。
  - 状态 `S`：src / tgt / maps / fmt / recipe / bad。改动走 `changed()` → `rebuild()`（重编函数）→ `render()` → `scan()`（全表扫错，60ms 防抖）。
  - 配方：localStorage `yijing.recipes.v1`，列按「列名」存，不按序号。丢新文件时用列名集合 Jaccard ≥0.6 且配方用到的列都在，就自动套，吐司可「不用」撤回。
- 每列 map：`{src:[列序号], cnst:null|固定值, op:{t:...}, conf:'sure'|'guess'|'blank'|'req'|'user', note}`。
- op 类型：none / date(from,to) / name(part) / join(sep,smart) / phone(cc,style) / num(dec,thou) / map(pairs) / case(mode)。

## 怎么测
```
cd 仓库根 && python3 -m http.server 8765
# Playwright：node 里 require('playwright')，chromium.launch()
# 页面挂了 window.__yj（S、loadFile、autoMap、parseDate…）和 window.__lastRead / __lastExport 计时
```
- 用 `page.setInputFiles('#fSrc', 文件)` 丢来源，`#fTgt` 丢目标模板，`#fRec` 导入配方。
- 390×844 和 1280×900 各跑：示例页、点一列开弹层、换模板、存配方、重丢文件看自动套配方、三种格式导出。
- 10 万行 × 11 列 CSV（9.9MB）实测（沙盒 Chromium）：读 0.31 秒；读+对列+全表扫错 0.84 秒；换模板重算 0.68 秒；导出 CSV 0.8 秒、JSON 1.3 秒、Excel 4.7 秒。

## 踩过的坑
- Playwright 无头 Chromium 下，`a.download` 文件名含非 ASCII（中文、→）时 `suggestedFilename()` 变成 `download`。真浏览器正常，没改；测试别拿这个当失败。
- 同义词「含在里面」只对中文 ≥2 字、英文 ≥4 字生效，不然「名」会吃掉「姓名」「公司名称」。`name`/`title`/`type`/`code` 这种多义词故意不进词典，只靠完全同名或模板里的 c 指定。
- 日期 a/b/yyyy 分不清日月时默认按 月/日/年 并标「存疑」。
- CSV 导出固定加 UTF-8 BOM（Excel 打开中文不乱码）；个别挑剔的导入器可能把 BOM 当表头一部分——待 Song 拍板。
- 「Tan Wei Ming」这类新马华人英文名，拆姓名会按西方规矩把最后一个词当姓。

## 还没做
值替换只能一对一（不支持规则/正则）；不能在目标模板里加列、改列名；没有「多行拆一行 / 一行拆多行」；没有 Web Worker（10 万行内不卡，100 万行没测）。
