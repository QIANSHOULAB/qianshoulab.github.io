# 巡山僧 · 上 Chrome 应用商店（照着点）

要贴的字在同一个文件夹的 `listing-en.md`、`listing-zh.md`、`privacy.md`，要拖的文件也都在这个文件夹（`xunshan/store/`）。下面按后台从上到下的顺序走。没提到的格子保持默认。

## 0. 开后台

1. 电脑浏览器打开 https://chrome.google.com/webstore/devconsole ，用 lunzigeju@gmail.com 登录。
2. 顶上要是有黄条让你验证联系邮箱（contact email）或开两步验证，先照它点完，不然最后提交不了。

## 1. 传包

1. 点左上 **New item**（新建）。
2. 把 `xunshan-0.4.1.zip` 拖进弹出来的框（或点 **Browse files** 选它）。
3. 传完自己跳到 **Store listing**（商店信息）页。名字、简介已经从包里读好了，不用填。

## 2. Store listing（商店信息）：英文

页面顶上语言是 **English**。

1. **Description**（详细说明）：贴 `listing-en.md` 里 Description 那一段。
2. **Category**（类别）：选 **Shopping**。
3. **Language**（语言）：选 **English**。
4. **Store icon**（商店图标）：拖 `icon-128.png`。
5. **Screenshots**（截图）：依次拖 `shots/en/1.png`、`2.png`、`3.png`、`4.png`。
6. **Small promo tile**（小宣传图）：拖 `promo-440x280.png`。
7. **Marquee promo tile**、**Global promo video**：空着。
8. **Official URL**：None。**Homepage URL**、**Support URL**：都填 `https://qianshoulab.github.io/xunshan/`。
9. **Mature content**（成人内容）：不勾。
10. 点 **Save draft**（存草稿）。

## 3. Store listing：中文

1. 页面顶上语言下拉换成 **Chinese (China)**（中文（中国））。
2. **Description**：贴 `listing-zh.md` 里 Description 那一段。
3. **Screenshots**：依次拖 `shots/zh/1.png`、`2.png`、`3.png`、`4.png`。
4. 这一页要是也要图标、小宣传图，就再拖一次 `icon-128.png`、`promo-440x280.png`。
5. 点 **Save draft**。

## 4. Privacy（隐私权）

全部照 `privacy.md` 贴：

1. **Single purpose description**（单一用途）：贴那一段。
2. **Permission justification**（权限理由）：每个权限一个框，按名字贴：storage、alarms、notifications、activeTab、scripting、offscreen、declarativeNetRequestWithHostAccess、Host permission。
3. **Remote code**（远程代码）：选 **No, I am not using Remote code**。
4. **Data usage**（数据使用）：只勾 **Website content**；底下三句声明全勾。
5. **Privacy policy URL**（隐私政策网址）：`https://qianshoulab.github.io/privacy/`
6. 点 **Save draft**。

## 5. Distribution（分发）

1. **Payments**（收费）：Free（免费，默认那个）。
2. **Visibility**（谁能看到）：**Public**（公开）。
3. **Regions**（地区）：**All regions**（全部地区）。
4. 点 **Save draft**。

## 6. Test instructions（给审核员的测试说明）

左边有这一页就填，没有就跳过：用户名、密码空着，**Additional instructions** 贴 `privacy.md` 最后那段英文。点 **Save draft**。

## 7. 提交

1. 点右上 **Submit for review**（提交审核）。
2. 弹框里 **Publish … automatically after it has passed review**（审核过了自动上架）保持勾着，再点弹框里的 **Submit for review**。
3. 审核结果发到 lunzigeju@gmail.com。被退回的话把邮件原文丢给 Claude，改完再交。
