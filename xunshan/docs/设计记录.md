# 巡山僧 · 设计记录（给接手的 Claude）

盯网页变化的浏览器插件（MV3，Chrome / Edge 120 起）。商店名「巡山僧 - 降价补货提醒」。对标 Distill Web Monitor、Visualping。0.1.0 开荒毛坯；0.2.0 精加工（复赛准 20/20 漏 0 误报 0）；0.2.1 二轮精加工：掐着点查 + 同站提前排队、历史截图、小窗同网址共用；0.3.0 三轮：去掉没必要的步骤（弹窗自己认价格库存、点一下就盯上、频率记住、一次贴一串网址、同站上回框过的那块直接认、删除改撤销）+ 照 _ops/设计规范.md 重做长相（见 bench/比武报告.md 末尾「0.3.0 复赛」）。

## 数据（全在 chrome.storage.local）

- `watches`：{ id → 盯梢 }。字段：url, title, label, kind（price|stock|seats|pick|page，认出来的是啥）, demo（示例，不真去看）, selector（null=整页）, alts（框选时记的备用选择器：类名/itemprop/data-testid，全页唯一的）, anchor {shape（数字换成 # 的字形，如 ¥#）, before（元素前面最近的 24 个字）}, numeric（框的时候是数字，找的时候认数字）, pickedText（框选当时看到的字，只用来判断要不要切小窗）, interval（分钟，1–1440）, cond {type: any|below|above|has|gone, value}, mode（fetch|frame；旧的 tab 当 frame）, paused, lastText, lastNum, lastNew（整页：最近新增的几行）, lastCheck, nextCheck, lastChange, lastHit, unread（触发了，红）, fresh（变了没触发，灰）, err, errCount, errNotified
- `shot:<id>`：{ 历史条目的 t → {src: webp dataURL, w, h, cw, ch} }。开盯和每次记进历史的变化各一张；每条最多 12 张（开盯那张一直留），单张 ≤ 90KB（超了缩小重压），全部照片合计 > 4MB 从最旧的删到 3.6MB（每条最新一张不删）。导出不带照片。
- `h:<id>`：历史数组 [{t, text, num, first?, hit?, moved?（改版重新找到）, added?（整页新增的行）}]，最多 40 条（保留第一条“开盯”）
- `settings`：defaultInterval（默认 30；0.3.0 起任何一条改频率都会跟着改，等于「记住上回的」）、hostGapSec（同一网站两次之间隔，默认 3 秒；旧的 siteGapSec 不再读）
- `chrome.declarativeNetRequest` 会话规则 id 1：去掉 x-frame-options / CSP 头，只对 tabIds=[-1]、initiatorDomains=[插件 id]、requestDomains=盯梢里 frame 模式或还没首查的网站

所有写操作都走后台消息（add / addMany / demo / patch / remove（交回删掉的整条）/ restore（撤销）/ checkNow / markAllRead / import / export / open / tick）。add 带 hold=true 时先记下不看，等 permissions.onAdded（放行了）再看第一眼——浏览器问「允许」时弹窗就算被关也不丢，避免页面和后台同时改丢数据。

## 检查怎么跑

1. 排班（`plan`）：按网站分组，每组取到期最早那条，加上到期时间差不到 90 秒（且不超过各自间隔 1/4）的，并成一批；已过点的全算进去。开工时刻 = 最早到期 − 同站间隔 ×（这批要抓的不同网址数 − 1），让最后一条也在到期那一刻前查完（临近到期提前抓）。`runDue()` 只跑开工时刻已到的批；不同网站最多 4 组一起跑，同一网站挨个查、间隔 hostGapSec（默认 3 秒）；同一网址这一轮只 fetch 一次，小窗模式同一网址只开一个 iframe 读齐（cache 的 `U:` / `F:` 键）。一轮结束算下一批开工时刻，45 秒内的用 setTimeout 掐着点醒（闹钟 30 秒一跳只当保底）；一轮没跑完又被叫，跑完立刻再排一次（again）。
   闹钟对齐：nextCheck = 这次该查的时刻 + 间隔（该查时刻在 [现在−间隔, 现在+间隔/2] 内才用，否则用现在），不按实际开查时间算，所以不会一轮轮往后漂，提前抓也不改节奏。
2. `check(id)`：先看有没有这个网站的权限 → mode=fetch 就 `fetch(url, credentials:'include')`，按 charset 解码，交给离屏页 DOMParser + `readPart`；mode=frame 就让离屏页开一个 sandbox iframe（不给 allow-top-navigation），加载完每 0.6–0.9 秒问一次 frame.js，最多 7 秒，读到就拆掉。用户窗口里不冒标签。
3. 第一次检查时，直接抓的结果对不上框选时看到的字（或找不到元素），自动试小窗，成了就把 mode 定成 frame。
4. 找元素（`locate`）：原路径 → 备用选择器（唯一的直接用；多个就挑字形对得上的）→ 文字锚点（字形一样 + 前面的字对得上，取最里层）；numeric 的要能认出数字。兜底找到 → 新路径写回 selector，历史记一笔 moved。都不行但原路径还有字（比如价格变「暂无报价」）就还用原路径。
5. 字变了 → 整页且「有变就叫」：只看新增行（数字一律当 #），没新增就当没变（不记、不叫，lastText 照更新）；有新增才记、才叫。框选的走 `shouldAlert`：低于/高于只叫好消息（刚越线；或已在线上又往好的方向走），往回走不叫。命中弹通知、标 unread、角标 +1；没命中标 fresh（灰）。
6. 出错（打不开 / 被拦 / 找不到 / 像登录页 / 没权限）→ 记 err，按 2^n 退避，被拦再 ×4，最多一天一次。连着 3 回出错发一条「盯不了了」通知（errNotified，只发一次，好了清零），点开总览页。识别验证码只是退，不绕。

6. 截图：记进历史的那一刻（开盯、变化；整页去噪不记的不拍）配一张。小窗模式在 frame.js 读完顺手 markup（字变了才抄，整页只在有新增行时抄），回离屏页 paint；直接抓的，拿同一份抓回来的 HTML 放进离屏页一个 `sandbox="allow-same-origin"`（不给 allow-scripts，网页脚本一行不跑）的 srcdoc iframe（加 `<base>` 借样式表），locate → markup → paint，排队一张张来，不挡巡山和通知。总览页历史里展开一条：文字对比下面放「之前 · 时间」「之后 · 时间」两张（之前 = 更早一条有照片的）。

## 权限

- 固定：storage, alarms, notifications, activeTab, scripting, offscreen, declarativeNetRequestWithHostAccess（这个不弹安装警告）
- 网站权限是 `optional_host_permissions`，用户在弹窗点「框选一块 / 盯整页」时按 `协议://主机/*` 现要；导入的清单在总览页顶部给一个「放行」按钮一次要齐。
- frame.js 用 `scripting.registerContentScripts` 注册在 http/https 全部 frame，但只有拿到权限的网站才会注入，进来一看不是自己的小窗就退。
- 没要 tabs、没要 <all_urls>、没要 unlimitedStorage。网站头像用字母，不去外面拉 favicon。
- 商店要填的每条理由在 docs/商店审核.md。

## 踩过的坑

- headless 不加 `channel:'chromium'` 时扩展的 service worker 起不来，等 serviceworker 事件超时。
- 没有 tabs 权限时 `chrome.tabs.query` 返回的 tab 没有 url（测试里要 `(t.url||'')`）。弹窗里因为有 activeTab 所以拿得到当前页 url。
- 框选面板里的点击会冒泡到网页的 document，网页的「点外面关菜单」之类会误触发 → 在 Shadow host 上 stopPropagation。
- Shadow DOM 里 `.row{display:flex}` 会盖掉 `hidden` 属性，要单独写 `[hidden]{display:none!important}`。
- 深色模式里用 `background:` 简写会把下拉箭头的 background-image 冲掉，用 `background-color`。
- 取字不能用 innerText：离屏页 DOMParser 出来的文档没排版，innerText 跟活页面不一致，会误报变化。自己写了 readText，两边一致。
- `pkill -f` 别带会出现在自己命令行里的词，会把自己的 shell 杀掉（用 `pkill -f "test/[s]ite.js 8787"`）。
- `timeout node e2e.js | tail`：node 被杀了 site.js 子进程还拿着管道，tail 永远不退。输出写文件。
- numeric 不能拿 lastNum 判断：库存「仅剩 3 件」→「缺货」会被当成找不到。用框选当时的字定。
- 离屏页 iframe 的 DNR 规则 `tabIds` 只有会话规则支持；会话规则浏览器重启就没，后台每次起来都 syncFrameRules。

- 离屏页里的跨站 iframe 不排版：里面 innerWidth=0、getBoundingClientRect 全 0，硬设 html 宽度也没用。所以截图拆成两步：iframe 里只抄带算好样式的标签（getComputedStyle 不靠排版也有值），排版和出图回到离屏页自己做（离屏页本身能排版）。
- 截图别等抓完再另开小窗去拍：网页可能已经又变了（测试里 1099 那张拍成了 899）。直接抓的要用同一份 HTML 拍。
- registerContentScripts 在 onInstalled 和顶层同时调会撞「Duplicate script ID」，要串成一个 promise；文件列表变了要先 unregister 再注册。
- 历史截图 img 的 CSS 不能写 width:auto，会盖掉 width 属性按 2 倍图原尺寸显示。

- 0.3.0：认价格时 BLOCK 级容器（.price-row）和里面的 .price 字一样长时，要跳过外层留里层，否则选择器指到容器上；「预售」「到货」这类词在公告标题里也有，库存只认 ≤16 字、不带日期的短字。
- 0.3.0：测试的 site.js 进程测试挂了会留着占端口，e2e.js 现在退出时一定 kill。

## 还糙的地方（下一步）

- 自动认价格是规则打分（货币符号、price 类名、itemprop、ld+json 的 price、字号、划线原价扣分），真大站（京东、淘宝、亚马逊）没在沙盒验过。认错了人点「自己框一块」改，认出来的那块框的时候会记住，同站下回照它认。

- 截图不带网页自己的图片和网页字体（灰块 + 系统字）、不带 ::before/::after，整页只拍上面 1400px、超 2000 个节点不拍。够看出哪变了，不是像素级截屏。
- 只有中文；strings.js 已经集中，加 en 块即可。
- 整页去噪把所有数字当一样：新公告只差日期数字会被忽略；要盯数字的请框选。
- Visualping、Distill 没比（沙盒连不上），要在 Song 的电脑上补。
