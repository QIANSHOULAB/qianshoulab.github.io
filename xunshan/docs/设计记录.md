# 巡山僧 · 设计记录（给接手的 Claude）

盯网页变化的浏览器插件（MV3，Chrome / Edge 通用）。对标 Distill Web Monitor、Visualping。0.1.0 是开荒毛坯。

## 目录

```
xunshan/
  index.html            介绍页（挂 https://qianshoulab.github.io/xunshan/）
  img/                  介绍页用的真截图（从 test/out 裁出来的 webp）
  dist/xunshan-0.1.0.zip  打好的插件包（= extension/ 目录压缩）
  extension/
    manifest.json
    lib/                千手院通用底子，跟业务无关，将来跟化缘僧、代笔僧合并
      strings.js        所有界面文字（QS.t / QS.applyT），加英文就加 en 块
      store.js          chrome.storage.local 封装：串行 update、设置带默认值
      page.js           读页面：readText（不依赖排版的取字）、parseNumber、cssPath、detectWall（验证码/登录墙识别）
      picker.js         网页上框选元素（Shadow DOM 隔离，↑ 放大一圈，Esc 退出）
      diff.js           文字对比（中文按字、英文按词，LCS）
      ui.css / ui.js    浅深色令牌、按钮/分段/开关、相对时间、toast、字母头像、图标
    core/rules.js       巡山僧业务：频率档、条件判断 shouldAlert、通知文案
    background.js       后台：闹钟、抓取、比对、通知、角标、全部消息处理
    offscreen.html/js   离屏页：DOMParser 解析抓回来的 HTML
    content/pick.js     框选后的面板（条件、频率、开盯）
    popup.*             工具栏弹窗
    app.*               总览页（也是 options_page）：列表、详情、历史对比、导入导出、设置
  test/
    site.js             本地测试店（价格/库存/公告可变、脚本渲染页、登录页、验证码页）
    e2e.js              端到端测试
  docs/
```

所有 lib 文件都是经典脚本，往 `globalThis.QS` 上挂东西，后台用 importScripts、页面用 `<script>`、内容脚本用 executeScript files 注入，三处通用。

## 数据（全在 chrome.storage.local）

- `watches`：{ id → 盯梢 }。字段：url, title, label, selector（null=整页）, pickedText（框选当时看到的字，只用来判断要不要切后台标签）, interval（分钟）, cond {type: any|below|above|has|gone, value}, mode（fetch|tab）, paused, lastText, lastNum, lastCheck, nextCheck, lastChange, lastHit, unread, err, errCount
- `h:<id>`：历史数组 [{t, text, num, first?, hit?}]，最多 40 条（保留第一条“开盯”）
- `settings`：defaultInterval（默认 30）、siteGapSec（同站最短间隔，默认 60 秒）
- `chrome.storage.session.hostHits`：每个网站上次被访问的时间

所有写操作都走后台消息（add / patch / remove / checkNow / markAllRead / import / export / open / tick），避免页面和后台同时改丢数据。

## 检查怎么跑

1. 闹钟 `tick` 每 1 分钟一次 → `runDue()` 挑到期的，同一网站一轮最多去一次（siteGapSec）。
2. `check(id)`：先看有没有这个网站的权限 → mode=fetch 就 `fetch(url, credentials:'include')`，按 charset 解码（GBK 站也行），交给离屏页 DOMParser + `readText` 取字；mode=tab 就开一个不抢焦点的后台标签，等加载完再等最多 6 秒让脚本渲染，注入 page.js 取字，关标签。
3. 第一次检查时，直接抓的结果对不上框选时看到的字（或找不到元素），自动试后台标签，成了就把 mode 定成 tab。脚本渲染页靠这个。
4. 字变了 → 记历史 → `shouldAlert` 判断条件 → 命中才弹通知、标未读、角标 +1。没命中只记历史。
5. 出错（打不开 / 被拦 / 元素没了 / 像登录页 / 没权限）→ 记 err，按 2^n 退避，被拦再 ×4，最多一天一次。识别验证码只是退，不绕。

## 权限

- 固定：storage, alarms, notifications, activeTab, scripting, offscreen
- 网站权限是 `optional_host_permissions`，用户在弹窗点「框选一块 / 盯整页」时按 `协议://主机/*` 现要；导入的清单在总览页顶部给一个「放行」按钮一次要齐。
- 没要 tabs、没要 <all_urls>、没要 unlimitedStorage。网站头像用字母，不去外面拉 favicon（免得把盯的网站透露给别人）。

## 怎么测

```
node xunshan/test/e2e.js          # 全部，含等真闹钟（约 2.5 分钟）
node xunshan/test/e2e.js --fast   # 跳过等闹钟
```

- 用 Playwright 的 chromium，`launchPersistentContext` + `--load-extension`，必须 `channel: 'chromium'` 才能 headless 加载扩展。
- 测试把扩展复制一份，manifest 加 `host_permissions: ["http://localhost/*"]`，因为权限弹窗自动化点不了。正式包不带。
- 弹窗不能在测试里真弹出来，用 `popup.html?tab=<标签id>` 当普通页面开。
- 通知点击用 `sw.evaluate(() => openWatch(id, nid))` 模拟（无头模式看不到通知本身，用 `chrome.notifications.getAll` 验证）。
- 截图在 `xunshan/test/out/`，介绍页的图从那里裁。

## 踩过的坑

- headless 不加 `channel:'chromium'` 时扩展的 service worker 起不来，等 serviceworker 事件超时。
- 没有 tabs 权限时 `chrome.tabs.query` 返回的 tab 没有 url（测试里要 `(t.url||'')`）。弹窗里因为有 activeTab 所以拿得到当前页 url。
- 框选面板里的点击会冒泡到网页的 document，网页的「点外面关菜单」之类会误触发 → 在 Shadow host 上 stopPropagation。
- Shadow DOM 里 `.row{display:flex}` 会盖掉 `hidden` 属性，要单独写 `[hidden]{display:none!important}`。
- 深色模式里用 `background:` 简写会把下拉箭头的 background-image 冲掉，用 `background-color`。
- 取字不能用 innerText：离屏页 DOMParser 出来的文档没排版，innerText 跟活页面不一致，会误报变化。自己写了 readText，两边一致。
- `pkill -f` 别带会出现在自己命令行里的词，会把自己的 shell 杀掉。

## 还糙的地方（下一步）

- 整页盯梢会被页面里的时间、在看人数之类噪音误报，需要「忽略数字 / 只看新增」选项。
- 后台标签模式会在用户的窗口里短暂冒出一个标签。可以换成离屏 iframe + declarativeNetRequest 去掉 X-Frame-Options，但要多申请权限。
- 选择器是 nth-of-type 路径，网页改版就会「找不到」。可加文本锚点 / 多选择器兜底。
- 历史里只存文字，不存截图（Visualping 的强项是截图对比）。
- 只有中文；strings.js 已经集中，加 en 块即可。
