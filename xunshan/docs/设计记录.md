# 巡山僧 · 设计记录（给接手的 Claude）

盯网页变化的浏览器插件（MV3，Chrome / Edge 120 起）。商店名「巡山僧 - 降价补货提醒」。对标 Distill Web Monitor、Visualping。0.1.0 开荒毛坯；0.2.0 精加工（复赛准 20/20 漏 0 误报 0，见 bench/比武报告.md 末尾）。

## 数据（全在 chrome.storage.local）

- `watches`：{ id → 盯梢 }。字段：url, title, label, selector（null=整页）, alts（框选时记的备用选择器：类名/itemprop/data-testid，全页唯一的）, anchor {shape（数字换成 # 的字形，如 ¥#）, before（元素前面最近的 24 个字）}, numeric（框的时候是数字，找的时候认数字）, pickedText（框选当时看到的字，只用来判断要不要切小窗）, interval（分钟，1–1440）, cond {type: any|below|above|has|gone, value}, mode（fetch|frame；旧的 tab 当 frame）, paused, lastText, lastNum, lastNew（整页：最近新增的几行）, lastCheck, nextCheck, lastChange, lastHit, unread（触发了，红）, fresh（变了没触发，灰）, err, errCount, errNotified
- `h:<id>`：历史数组 [{t, text, num, first?, hit?, moved?（改版重新找到）, added?（整页新增的行）}]，最多 40 条（保留第一条“开盯”）
- `settings`：defaultInterval（默认 30）、hostGapSec（同一网站两次之间隔，默认 3 秒；旧的 siteGapSec 不再读）
- `chrome.declarativeNetRequest` 会话规则 id 1：去掉 x-frame-options / CSP 头，只对 tabIds=[-1]、initiatorDomains=[插件 id]、requestDomains=盯梢里 frame 模式或还没首查的网站

所有写操作都走后台消息（add / patch / remove / checkNow / markAllRead / import / export / open / tick），避免页面和后台同时改丢数据。

## 检查怎么跑

1. 闹钟 `tick` 每 30 秒一次 → `runDue()` 挑到期的，按网站分组：不同网站最多 4 组一起跑，同一网站挨个查、两次之间隔 hostGapSec（默认 3 秒）；同一网址这一轮只 fetch 一次（cache）。一轮没跑完下一跳直接跳过（roundBusy）。nextCheck 按检查开始时间算，不漂。
2. `check(id)`：先看有没有这个网站的权限 → mode=fetch 就 `fetch(url, credentials:'include')`，按 charset 解码，交给离屏页 DOMParser + `readPart`；mode=frame 就让离屏页开一个 sandbox iframe（不给 allow-top-navigation），加载完每 0.6–0.9 秒问一次 frame.js，最多 7 秒，读到就拆掉。用户窗口里不冒标签。
3. 第一次检查时，直接抓的结果对不上框选时看到的字（或找不到元素），自动试小窗，成了就把 mode 定成 frame。
4. 找元素（`locate`）：原路径 → 备用选择器（唯一的直接用；多个就挑字形对得上的）→ 文字锚点（字形一样 + 前面的字对得上，取最里层）；numeric 的要能认出数字。兜底找到 → 新路径写回 selector，历史记一笔 moved。都不行但原路径还有字（比如价格变「暂无报价」）就还用原路径。
5. 字变了 → 整页且「有变就叫」：只看新增行（数字一律当 #），没新增就当没变（不记、不叫，lastText 照更新）；有新增才记、才叫。框选的走 `shouldAlert`：低于/高于只叫好消息（刚越线；或已在线上又往好的方向走），往回走不叫。命中弹通知、标 unread、角标 +1；没命中标 fresh（灰）。
6. 出错（打不开 / 被拦 / 找不到 / 像登录页 / 没权限）→ 记 err，按 2^n 退避，被拦再 ×4，最多一天一次。连着 3 回出错发一条「盯不了了」通知（errNotified，只发一次，好了清零），点开总览页。识别验证码只是退，不绕。

## 权限

- 固定：storage, alarms, notifications, activeTab, scripting, offscreen, declarativeNetRequestWithHostAccess（这个不弹安装警告）
- 网站权限是 `optional_host_permissions`，用户在弹窗点「框选一块 / 盯整页」时按 `协议://主机/*` 现要；导入的清单在总览页顶部给一个「放行」按钮一次要齐。
- frame.js 用 `scripting.registerContentScripts` 注册在 http/https 全部 frame，但只有拿到权限的网站才会注入，进来一看不是自己的小窗就退。
- 没要 tabs、没要 <all_urls>、没要 unlimitedStorage。网站头像用字母，不去外面拉 favicon。
- 商店要填的每条理由在 docs/商店审核.md。

## 怎么测

```

node xunshan/test/e2e.js --fast   # 跳过等闹钟
```

- 用 Playwright 的 chromium，`launchPersistentContext` + `--load-extension`，必须 `channel: 'chromium'` 才能 headless 加载扩展。
- 测试把扩展复制一份，manifest 加 `host_permissions: ["http://localhost/*"]`，因为权限弹窗自动化点不了。正式包不带。
- 49 项：含小窗（页面带 X-Frame-Options: DENY）、小窗带登录、整页去噪、改版重新找到、只叫好消息、连错 3 回发通知、同站排队、同网址只抓一次。

- 弹窗不能在测试里真弹出来，用 `popup.html?tab=<标签id>` 当普通页面开。

## 踩过的坑

- headless 不加 `channel:'chromium'` 时扩展的 service worker 起不来，等 serviceworker 事件超时。
- 没有 tabs 权限时 `chrome.tabs.query` 返回的 tab 没有 url（测试里要 `(t.url||'')`）。弹窗里因为有 activeTab 所以拿得到当前页 url。
- 框选面板里的点击会冒泡到网页的 document，网页的「点外面关菜单」之类会误触发 → 在 Shadow host 上 stopPropagation。
- Shadow DOM 里 `.row{display:flex}` 会盖掉 `hidden` 属性，要单独写 `[hidden]{display:none!important}`。
- 深色模式里用 `background:` 简写会把下拉箭头的 background-image 冲掉，用 `background-color`。
- 取字不能用 innerText：离屏页 DOMParser 出来的文档没排版，innerText 跟活页面不一致，会误报变化。自己写了 readText，两边一致。
- `pkill -f` 别带会出现在自己命令行里的词，会把自己的 shell 杀掉（用 `pkill -f "test/[s]ite.js 8787"`）。
- `timeout node e2e.js | tail`：node 被杀了 site.js 子进程还拿着管道，tail 永远不退。输出写文件。
- numeric 不能拿 lastNum 判断：库存「仅剩 3 件」→「缺货」会被当成找不到。用框选当时的字定。
- 离屏页 iframe 的 DNR 规则 `tabIds` 只有会话规则支持；会话规则浏览器重启就没，后台每次起来都 syncFrameRules。
