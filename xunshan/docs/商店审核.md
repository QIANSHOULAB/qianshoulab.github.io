# 巡山僧 · 商店审核要填的（0.4.0）

照 Chrome 应用商店「隐私权做法」页的栏目写，Edge 加载项后台的栏目基本一样。这份中文给自己看；英文版在 [商店审核.en.md](商店审核.en.md)，整段直接贴。**还没提交**，提交前对一遍 manifest 的权限有没有变。

- 商店名字跟浏览器语言走（manifest 用 `_locales`，`default_locale` 是 `en`）：
  - 英文：Xunshan · Price Watch – Drop & Restock Alerts
  - 中文（`zh_CN`）：巡山僧 - 降价补货提醒（拍板 3B：带上大家搜的「降价」「补货」）
  - 短名：Xunshan / 巡山僧
- 商店简介（≤ 132 字符）：英文、中文各一句，在 `extension/_locales/*/messages.json` 的 `extDesc`。
- 插件里面的语言不跟浏览器走：默认英文，弹窗和总览页右上角 EN / 中文 切换，选过就记住。审核员看到英文界面是正常的。
- 类别：Shopping（购物）；备选 Productivity

## 单一用途

> 盯住用户自己选的网页（或网页里的一块），定时去看，内容变了、或到了用户设的条件（低于 / 高于某个数、出现 / 消失某个词），弹系统通知。

## 每个权限的理由

| 权限 | 为什么要（英文版有整句） |
|---|---|
| storage | 盯梢清单、变化记录、截图、设置、语言，全存在本机 chrome.storage.local |
| alarms | 30 秒醒一次当保底，到点的去看 |
| notifications | 变了、到线了弹通知；连着几回看不成也说一声 |
| activeTab | 点工具栏图标时看一眼当前页，认出价格、库存那块，点一下就能盯 |
| scripting | 认价格、自己框一块时往当前页注入；另外注册一个只在插件自己离屏小窗里干活的内容脚本 |
| offscreen | 离屏页里解析抓回来的网页、在看不见的小窗里读脚本页、拍变化前后的小截图 |
| declarativeNetRequestWithHostAccess | 会话规则只对插件自己发起、只对盯梢里的网站去掉 X-Frame-Options / CSP 头，正常上网不受影响 |
| 网站权限（optional） | 用户第一次盯某个网站时按 `协议://主机/*` 现要，装的时候一个都不要 |

## 远程代码

没有。全部 JS 打在包里；抓回来的网页只当数据解析，或放进 sandbox 小窗。

## 数据使用

勾选：**网站内容**——只为了比对变化，存在本机。其余全不勾。三条声明全勾：不卖给第三方；不用于与单一用途无关的目的；不用于判断信用、放贷。

## 给审核员的测试说明

英文版里有整段。大意：随便开一个带价格的商品页 → 点工具栏图标，弹窗自己认出价格那行 → 点那行就盯上（第一次这个网站浏览器问一次权限）→ 想设线点 Below 打个数 → 右键图标「选项」打开总览，Check now 立刻看一次。不用账号，不用登录。
