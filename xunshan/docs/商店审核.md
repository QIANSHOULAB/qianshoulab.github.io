# 巡山僧 · 商店审核要填的（0.2.1）

照 Chrome 应用商店「隐私权做法」页的栏目写，Edge 加载项后台的栏目基本一样。中文给自己看，英文直接贴。**还没提交**，提交前对一遍 manifest 的权限有没有变。

- 商店名字：巡山僧 - 降价补货提醒（manifest `name`），短名「巡山僧」
- 类别：Shopping（购物）；备选 Productivity

## 单一用途 Single purpose

> 盯住用户自己选的网页（或网页里框选的一块），定时去看，内容变了、或到了用户设的条件（低于/高于某个数、出现/消失某个词），弹系统通知。

> Watches web pages (or a part of a page the user selects) that the user chose, re-checks them on a schedule, and shows a notification when the content changes or meets the user's condition (price below/above a number, a word appears/disappears).

## 每个权限的理由 Permission justification

| 权限 | 英文理由（直接贴） |
|---|---|
| storage | Stores the user's watch list, history of detected changes and settings locally in chrome.storage.local. Nothing is sent to any server. |
| alarms | Wakes the extension every 30 seconds (as a fallback to a precise in-worker timer) to re-check watches whose interval (1 minute to 1 day, chosen by the user) has elapsed. |
| notifications | Shows a system notification when a watched page changes or meets the user's condition, and when a watch keeps failing (e.g. the page now requires login). |
| activeTab | When the user clicks the toolbar button, reads the current tab's URL and title and looks at the page once (in the user's own browser) to find the price / stock block, so the user can start watching it with one click. Nothing leaves the browser. |
| scripting | Injects the element picker into the current tab only when the user opens the popup (to find the price / stock block) or clicks "自己框一块" (pick a part), and registers a tiny content script that only runs inside the extension's own offscreen frame (see below) to read the selected part of a script-rendered page. |
| offscreen | Uses an offscreen document to (1) parse fetched HTML with DOMParser, and (2) load script-rendered pages the user chose to watch in a hidden iframe, so no tabs ever pop up in the user's window, and (3) draw a small local snapshot image of the watched part when it changes (stored only in chrome.storage.local, shown in the change history). |
| declarativeNetRequestWithHostAccess | Some sites send X-Frame-Options / CSP frame-ancestors, which stop the hidden iframe above from loading. A **session** rule removes those response headers **only** for sub-frame requests that (a) are initiated by this extension itself (`initiatorDomains: [extension id]`, `tabIds: [TAB_ID_NONE]`) and (b) go to hosts the user has added to the watch list. Normal browsing is never affected. The rule list is rebuilt from the watch list every time it changes. |
| Host permissions (optional_host_permissions `http://*/*`, `https://*/*`) | Requested at runtime, one site at a time (`https://example.com/*`), when the user clicks "框选一块" or "盯整页" on that site. Needed to fetch the page on schedule with the user's own login cookies and to read it. No host permission is granted at install. |

## 远程代码 Remote code

> No. All JavaScript is packaged in the extension. Fetched pages are only parsed as data (DOMParser) or loaded in a sandboxed hidden iframe (`sandbox="allow-scripts allow-same-origin allow-forms"`, no top navigation); for snapshots of fetched pages, the fetched HTML is laid out in a `sandbox="allow-same-origin"` srcdoc iframe with scripts disabled. The extension never evals page content.

## 数据使用 Data usage

勾选：**网站内容**（Website content）——只为了比对变化，存在本机。其余全不勾。

> The extension reads the content of pages the user explicitly chose to watch, only to detect changes. The watch list, snapshots and history are stored only in the user's browser (chrome.storage.local). No data is sent to the developer or any third party; there are no analytics, no accounts, no remote servers. Site avatars are drawn from the first letter of the host name, not fetched from a favicon service.

三条声明全勾：不卖给第三方；不用于与单一用途无关的目的；不用于判断信用、放贷。

## 给审核员的测试说明 Test instructions

> 1. Open any product page, e.g. a page with a price. 2. Click the toolbar icon → "框选一块" (pick a part) → allow the site permission → click the price → choose "低于" (below) and type a number above the current price → "开盯" (start). 3. The dashboard (right-click icon → Options) lists the watch; "现在就看" (check now) re-checks immediately. No account or login is needed.
