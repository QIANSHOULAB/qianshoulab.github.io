# Xunshan · Price Watch: store listing and review answers (0.4.0)

Everything below is ready to paste into the Chrome Web Store dashboard (the Edge Add-ons fields are nearly the same). **Not submitted.** Before submitting, check the permissions in `extension/manifest.json` still match this page.

## Listing

- **Name:** Xunshan · Price Watch – Drop & Restock Alerts (Chinese browsers get 巡山僧 - 降价补货提醒; both come from `extension/_locales`, default locale `en`)
- **Short name:** Xunshan
- **Summary (≤ 132 characters):** Watches pages for price drops, restocks and new posts, and pings you the moment something moves. Your list stays in your browser.
- **Category:** Shopping (alternative: Productivity)
- **Language:** English (the extension also ships a Chinese UI; the EN / 中文 switch is in the top-right corner of the popup and the overview page)

### Description

> Stares at the page so you don't have to.
>
> Open a product page and click Xunshan. It finds the price and the stock status on its own; one click and it's watching. Prices alert on any drop by default, sold-out items alert when they're back. Want a threshold? Click Below and type a number.
>
> - Good news only: alerts when a price crosses your line or drops further. It goes back up? Silence.
> - Quiet on busy pages: ticking clocks and viewer counts don't count, only new content does.
> - Survives redesigns: when a page gets a makeover, it finds your spot again.
> - Script-heavy pages and pages behind a login work too, using the login already in your browser. No tabs pop up.
> - Paste a whole list of URLs at once and set one "below" price for all of them.
> - Every change comes with a before / after snapshot.
> - Says when it's stuck (captcha, login page, missing element) instead of failing quietly.
>
> No account, no server, no analytics. Your watchlist, history and snapshots stay in your browser.

## Single purpose

> Watches web pages (or a part of a page) that the user chose, re-checks them on a schedule, and shows a notification when the content changes or meets the user's condition (price below/above a number, a word appears/disappears).

## Permission justification

| Permission | Justification |
|---|---|
| storage | Stores the user's watchlist, the history of detected changes, small snapshots, settings and the chosen UI language locally in chrome.storage.local. Nothing is sent to any server. |
| alarms | Wakes the extension every 30 seconds (as a fallback to a precise in-worker timer) to re-check watches whose interval (1 minute to 1 day, chosen by the user) has elapsed. |
| notifications | Shows a system notification when a watched page changes or meets the user's condition, and when a watch keeps failing (for example, the page now requires a login). |
| activeTab | When the user clicks the toolbar button, reads the current tab's URL and title and looks at the page once (in the user's own browser) to find the price / stock block, so the user can start watching it with one click. Nothing leaves the browser. |
| scripting | Injects the price / stock finder into the current tab only when the user opens the popup, and the element picker only when the user clicks "Pick an area". Also registers a tiny content script that runs only inside the extension's own offscreen frame (see below) to read the selected part of a script-rendered page. |
| offscreen | Uses an offscreen document to (1) parse fetched HTML with DOMParser, (2) load script-rendered pages the user chose to watch in a hidden iframe, so no tabs ever pop up in the user's window, and (3) draw a small local snapshot of the watched part when it changes (stored only in chrome.storage.local, shown in the change history). |
| declarativeNetRequestWithHostAccess | Some sites send X-Frame-Options / CSP frame-ancestors, which stop the hidden iframe above from loading. A **session** rule removes those response headers **only** for sub-frame requests that (a) are initiated by this extension itself (`initiatorDomains: [extension id]`, `tabIds: [TAB_ID_NONE]`) and (b) go to hosts the user has added to the watchlist. Normal browsing is never affected. The rule is rebuilt from the watchlist every time it changes. |
| Host permissions (optional_host_permissions `http://*/*`, `https://*/*`) | Requested at runtime, one site at a time (`https://example.com/*`), the first time the user watches something on that site. Needed to fetch the page on schedule with the user's own login cookies and to read it. No host permission is granted at install. |

## Remote code

> No. All JavaScript is packaged in the extension. Fetched pages are only parsed as data (DOMParser) or loaded in a sandboxed hidden iframe (`sandbox="allow-scripts allow-same-origin allow-forms"`, no top navigation); for snapshots of fetched pages, the fetched HTML is laid out in a `sandbox="allow-same-origin"` srcdoc iframe with scripts disabled. The extension never evals page content.

## Data usage

Tick **Website content** only (used to detect changes, stored locally). Leave everything else unticked.

> The extension reads the content of pages the user explicitly chose to watch, only to detect changes. The watchlist, snapshots and history are stored only in the user's browser (chrome.storage.local). No data is sent to the developer or any third party; there are no analytics, no accounts, no remote servers. Site avatars are drawn from the first letter of the host name, not fetched from a favicon service.

Tick all three certifications: not sold to third parties; not used for purposes unrelated to the single purpose; not used to determine creditworthiness or for lending.

## Test instructions for the reviewer

> 1. Open any product page that shows a price.
> 2. Click the Xunshan toolbar icon. The popup finds the price (and stock, if there is one) by itself.
> 3. Click the price row. The browser asks once for permission to access that site; allow it. The row now says "Watching · Any drop".
> 4. Optional: click "Below" and type a number above the current price, then press Enter.
> 5. Right-click the icon → Options to open the overview. "Check now" re-checks immediately; the change history and snapshots appear below.
> 6. No account or login is needed. "Try a demo" in an empty popup adds a sample watch that already has a price drop.
> 7. The UI language switch (EN / 中文) is in the top-right corner; English is the default.
