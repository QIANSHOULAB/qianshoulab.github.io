# Zero-Flesh Creation · 零肉身造物

https://zeroflesh.github.io/

A door on the horizon. Scroll, and it makes things: a sun, a ring, a whale, an armillary, the law. Five ways in: QIANSHOU LAB, the Cyber Bodega, Specimens, Artifacts and the Codex.

- Source: `_zero/` (Astro, MDX, Tailwind, three.js; see `_zero/README.md`). `.github/workflows/zero.yml` builds it into the repo root; GitHub Pages serves the root of `main`.
- QIANSHOU LAB and its tools stay at https://qianshoulab.github.io/qianshou/ .

源码在 `_zero/`，工作流构建以后把产物提交到仓库根目录，Pages 从 main 根目录发。11-28 从 qianshoulab.github.io 搬来；千手院和各个工具照旧在 https://qianshoulab.github.io/qianshou/ 。
