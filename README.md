# 千手院 · QIANSHOU LAB

千手院总舵主页，网址：https://qianshoulab.github.io/ （仓库得叫 qianshoulab.github.io 才挂在根上）

- 每次打开随机换一套皮：A「千手法相」（千手千眼的光环）或 B「赛博山门」（霓虹牌坊和五层宝塔）。
  想指定就在网址后面加 `?a` 或 `?b`。
- 3D 是网页自己用 three.js 现画的，没有图片：`scene-a.js`、`scene-b.js`。
- GitHub Pages 从 `main` 分支根目录发布。

在岗罗汉：

- [录入僧](https://qianshoulab.github.io/luruseng/)：施主去玩，贫僧填表
- [渡表僧](https://qianshoulab.github.io/pabiao/)：表丢来，你去玩，贫僧超度（PDF 转 Excel，扫描件也认，文件不上传）
- [洗表僧](https://qianshoulab.github.io/xibiao/)：施主手抖，贫僧搓澡（表格清洗，文件不上传）
- [译经僧](https://qianshoulab.github.io/yijing/)：施主搬家，贫僧译经（A 系统导出翻成 B 系统导入格式，网页）
- [抄经僧](https://qianshoulab.github.io/chaojing/)：名单丢来，贫僧一行抄一份（Word 模板 + Excel 批量出证书、发票、合同，网页）
- [包租僧](https://qianshoulab.github.io/baozuseng/)：施主收租，贫僧掰账（二房东记账，手机网页，账只存手机）
- [化缘僧](https://qianshoulab.github.io/huayuan/)：点一下，你去玩，贫僧挨页化缘（网页名单抓成 Excel，Chrome / Edge 插件）
- [巡山僧](https://qianshoulab.github.io/xunshan/)：施主去睡，贫僧盯着（降价补货提醒，Chrome / Edge 插件）
- [代笔僧](https://qianshoulab.github.io/daibi/)：施主喝茶，贫僧代笔（Excel 一行行填进网页表单，Chrome / Edge 插件）
- [知客僧](https://qianshoulab.github.io/zhike/)：收发室那点活，贫僧包了（邮件分拣，Windows 电脑版）
- [扫地僧](https://qianshoulab.github.io/saodi/)：文件乱扔，你去玩，贫僧扫（文件批处理，Windows 电脑版）

小工具：
