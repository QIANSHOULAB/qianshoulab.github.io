# 抄经僧 · 设计记录（给接手的 Claude）

批量出文档：Word 模板 + 表格，一行出一份，打包 zip。纯前端，`index.html` + `strings.js`（界面文字）+ `lib/` 里的第三方库。英文名 Chaojing · Doc Batcher。

## 结构

- `strings.js`（0.4.0）：界面上的字全在这儿，`CJ_STRINGS.zh` / `CJ_STRINGS.en` 两套，键一一对应（`strings_dump.js` 会把两边都导出来，缺键一眼看得出）。英文是照英文习惯重写的，不是翻译。每套里还有 `examples`：三个示例（证书横版带花边 / 发票 / 录用通知），中文一套、英文一套（英文名字、美元、美式日期，人名公司全是编的），模板以「编辑器 HTML」存，开机时 `htmlToDocx()` 现做成 .docx。文件名兜底（`fileN`）、zip 名（`zipName`）、列表分隔符（`sep`）、日期（`date`）、粘贴框示意、编辑器起手模板也在这里。
- 挑语言（Song 11-03 22:19：默认英文，第二语言中文，不跟浏览器语言走）：`<head>` 里一小段脚本，`?lang=zh|en`（只管这一次）> 右上角选过、记在 localStorage `chaojing.lang` 的 > 默认 `CJ_DEFAULT_LANG`（en）；画页面之前就把 `<html lang>`、`<title>`、meta description、主屏图标名换好。静态 HTML 里写的也是英文那套。右上角 `#langSeg`（EN / 中文 小分段控件，钮上的字在 `CJ_LANGS`，两种界面一样）走 `setLang()`：界面字全换，正在看示例就换成这门语言的示例，用户自己的模板、表格、成品一个字不动。
- `index.html`：全部 CSS + JS。脚本按块分：
  - `T`：当前语言那套字（`let T=CJ_STRINGS[LANG]`，`applyT()` 填 `data-t`）；`EXAMPLES=T.examples`。新加界面字只往 `strings.js` 两套里加，`index.html` 里不许再写死字。
  - `extractTags()`：解 docx（PizZip），按段落拼 `<w:t>` 文本后正则找 `{{…}}`，能认被 Word 拆成多个 run 的空位；含页眉页脚。
  - `makeDoc()/fillDocx()`：docxtemplater，分隔符 `{{ }}`，自定义 parser 允许 `{{ 姓名 }}` 带空格。
  - 对号入座 `S.map[tag]`：列号；`-1` 没对上（原样保留 `{{tag}}`，故意让人看见）；`-2` 留空。`autoMap()`：去空格/标点小写后精确匹配 → 互相包含 → 沿用旧选择。
  - `htmlToDocx(html, orient, border)`：编辑器 HTML → 最小 docx（段落、加粗斜体下划线、颜色、字号 span、对齐、分隔线、表格、页面花边 pgBorders）。
  - 预览：`docx-preview` 把填好的 docx 画成 HTML，`fitPreview()` 按宽度缩放。
  - 分组 `computeUnits()`：模板表格行（`trTags()`）外面的空位当「表头」，连续几行表头值一样、又有一列像单号（每组一个、不重复、不空）、表格行里的值不一样 → 并成一份（`S.units` 每份一组行号）。表头全空的行算上一份的续行。`groupBuf()` 在要循环的 `<w:tr>` 里插 `{{-w:tr __g}}…{{/__g}}`；`unitValues(u)` 给 `__g` 数组。`S.noGroup` 是「拆开」开关。
  - PDF（0.2.0 重写，真字）：`pdfSession()` 先按这批要用的字从 `fonts/` 搬 Noto Sans SC 的块（Cache Storage 缓存），在隐藏 iframe `#renderer` 里注册成 `QSans` 并强制所有字用它；模板填「记号」（`\uE000序号\uE001`，循环行 `\uE002`）排一次，`wireProbe()` 把记号换成 `<q-v>` 小格子；每份 `applyUnit()` 只改字/复制表格行 → `extractDoc()` 用 Range 逐字读位置、读边框底色图片 → `paginate()` 超页按行切、页眉页脚每页都有 → `pdfJob()` 发给后台线程 `pdfWorker`（自己写 PDF：TrueType 子集化、Identity-H、ToUnicode、TJ 逐字定位）。字体里没有的生僻字画成小图 + 隐形文字层。模板有用户自己的 `{{#…}}` 时 `fast=false`，每份 docx-preview 重排。
  - 生成：Word 在主线程填（DEFLATE），PDF 主线程排版、后台 2～6 个线程写；zip 外层 STORE。文件名规则 `{{列名}}`，非法字符换 `_`，重名加 `(2)`，命名列全空退成「第 N 份」。
  - 排版前处理（0.2.1）`prepDocx()`：预览和 PDF 渲染前都过一遍（Word 成品不动）。① 读 numbering.xml 自己算编号写成真字插段首（`number()`/`fmtNum()`），删掉段落和样式里的 numPr，免得 docx-preview 再画 CSS 计数器；编号定义的缩进补进段落，后缀是制表符时插 `_qn` 书签，排好后 `fixNumTabs()` 按悬挂缩进算宽（用 padding-left 撑，样式表把 word-spacing/font-size 归零——docx-preview 会异步改行内样式）。② 每段算出 keepNext/keepLines/widowControl（段落→样式链→docDefaults），插 `_qk{NLW}n` 书签；`extractSection()` 认出来，`paginate()` 切页时 `keepCut()` 挪切点。③ 没写样式的段落显式挂默认样式（不然 docx-preview 不给字套正文字号）。
  - 字体三套（0.2.1）：`FAMS` s=黑体 Noto Sans SC、r=宋体 Noto Serif SC、k=楷体 霞鹜文楷。`markFonts()` 读每个元素算出来的 font-family，`fontFam()` 归类后打 `data-qf`，样式表按 `data-qf` 指到 QSans/QSerif/QKai（后面都跟 QSans 兜底）。PDF 里每个字先看本套有没有，没有用黑体，再没有画图；后台线程字体键是 `族+字重`（如 `r700`）。预览页用 `pageFaces()` 挂 @font-face 按块懒加载。
  - 西文字体（0.4.1）：`FAMS` 再加 l=Noto Sans（配黑体）、t=Noto Serif（配宋体、楷体），`LATIN={s:"l",r:"t",k:"t"}`，文件在 `fonts/latin/`、`fonts/latin-serif/`（各 latin、latin-ext 两块）。分两类字：`isLat`（拉丁字母、数字、西文符号）一律走西文字体；`isAmb`（弯引号、破折号、省略号、间隔号这类中西都用的标点）只在 `<p data-ql>` 里走西文字体，`markLatin()` 给「没有中文、有拉丁字母」的段落打这个记号（排版后、每份换字后都重算）。排版 iframe 里同一块西文字体注册两次：QLatS（isLat 的 unicode-range）和 QLatSX（isAmb 的），样式表按有没有 data-ql 决定挂不挂 QLatSX。两类都不含空格，所以每个元素的主字体（基线、行高）还是中文那套，`ASC` 不用动。`extractSection()` 按同一规矩给每个字挑 `l/t`，这块西文字体没装进 iframe（`FACES`）就退回中文字体，跟浏览器排的一致。西文字体下不来（断网）就照旧用中文字体里的西文，不报错。
  - 后台线程（0.4.1）：压缩 `z()` 直接往 `CompressionStream` 的 writer 里写（原来绕 `Blob.stream().pipeThrough()`，每块固定开销 1.8 毫秒，小块 1000 次 1.8 秒对 0.11 秒）；字体子集按「字体 + 排好序的字」缓存 64 个（`FCACHE`），标题粗体这种每份一样的子集只切一次、压一次。
  - 界面（0.3.0 重做，照 `_ops/设计规范.md`）：`body.empty` 时只显示 `#vEmpty`（大标题 + 丢文件 +「用示例试试」），有了模板或表格切到 `#vWork`（左 文件 / 对号入座 / 出货，右预览；手机下载钮 `.dock` 贴底）。`renderAll()` 统一刷。模板和表格可以只有一个：缺的那行写「还差…」，只有模板时预览画模板原样。错误走 `showErr([一句话, 怎么办])`，显示在 `#err0`（空状态）/`#err1`（文件卡），不用 toast。
  - 丢文件 `takeFiles()`：一个 `#fAny`（multiple）+ 整页 drop，按后缀分，先模板后表格。换成自己的模板 / 表格时，另一半如果是示例就撤下。
  - 记性（0.3.0）：`M`（localStorage `chaojing.mem.v1`）存 `fmt`、`rules[tplKey]`、`maps[tplKey][tag]=列名|""(留空)`，`tplKey`=模板名+排序后的空位；`autoMap()` 先看记住的再按名字对。上回的模板和表格存 IndexedDB `chaojing/kv`（`tpl`、`data`，示例不存），开机 `restoreLast()` 接上，`S.restored` 时文件卡底下显示「接着上回的 · 清掉」，清掉的 toast 带「撤销」。
- 图标：`icon.svg`（跟总舵首页卡片同一个图形）当 favicon；`apple-touch-icon.png` 由 `bench/shots_03.js` 从它生成（满版方图，iOS 自己切圆角）。
- `lib/`：库清单和许可见 `lib/README.md`。xlsx 按需加载。`fonts/`：黑体 `400/ 700/ index.json`，宋体 `serif/`，楷体 `kai/`，各自 切块 woff + `index.json`（字→块），`make_index.py` 生成索引；只在用到时搬。

## 怎么测

```
cd 仓库根 && python3 -m http.server 8765   # 端口被占就换一个，run_ours.js 认 CHAOJING_URL
# Playwright：打开 http://localhost:8765/chaojing/ ，1280 和 390 宽各跑：
#   示例 → 生成 Word / 都要 → 切发票、录用通知出 PDF → 上传 Word 模板（拆 run 的空位、页眉、表格）
#   → 上传 500 行 xlsx → 生成 500 份 Word、PDF → GBK 编码 CSV → 在线编辑插空位 → 粘贴表格
# 产物用 python zipfile 解（Debian 的 unzip 不认 UTF-8 文件名标志，会显示 #U...，不是我们的 bug）
# docx 用 soffice --headless --convert-to pdf 再 pdftoppm 看版式；PDF 直接 pdftoppm
```

`window.__lastRun` 记录最近一次生成的份数/秒数/字节；`window.__api` 暴露内部函数方便测。

实测（沙盒 Chromium 4 核，2026-11-03，0.2.1）：500 行发票 → Word 4.7 秒；→ PDF 6～8 秒、16.3 MB，0 错。

比武：`bench/gen_materials.py` 出五套材料（含 0.2.1 的通知套），`check.py` 对字，`check_layout.py` 对版式。

0.4.0 起（中英两套）：`bench/flow_04.js`（英文、中文界面 × 1280、390 真流程；英文那遍故意用 zh-CN 浏览器开、中文那遍用 en-US 开再点「中文」，查默认英文不跟浏览器、选了记住；外加 `<html lang>` / 标题 / 简介跟着切、英文界面没漏中文、按钮没撑破没折行）；`bench/shots_04.js`（中英 × 390 / 1280 × 空状态 / 结果 8 张，`EXTRA=1` 多拍英文发票、在线编辑、出错、深色）；`bench/strings_dump.js`（中英文字清单 `bench/strings-0.4/zh.txt`、`en.txt`，一行一条）。`flow_03.js` 是中文选择器，跑它要在网址后面加 `?lang=zh`。

## 踩过的坑

- 主页面的 `Uint8Array` 传进 iframe，iframe 里的 JSZip 用 instanceof 判断，不认 → 必须 `new w.Uint8Array(bytes)`。
- docx-preview 不画 `w:pgBorders`，自己解析后用 `section.docx::before` 补（`pageBorder()/borderCss()`）。
- docx-preview `inWrapper:false` 时纸是透明的，要自己给 `section.docx` 白底。
- 编辑器空行 `<p><br></p>`：浏览器里末尾 br 不占行，Word 里会多一行 → 转换时丢掉段末 br。
- 中文 Excel 导出的 CSV 多是 GBK：先 UTF-8 fatal 解，失败再 gb18030。
- 预览（docx-preview）的行距比 Word 紧一点，大字号尤其明显；PDF 是按预览截的图，所以 PDF 也偏紧。Word 文件本身没问题。
- `.field` 类名被出货卡和编辑器工具栏撞了，工具栏改用 `.fld`。
- SheetJS 0.18.5 解 `&#134071;` 这种数字实体用 `fromCharCode`，扩展B区生僻字（𠮷）被截成「ஷ」。已在 `lib/xlsx.full.min.js` 改成 `fromCodePoint`（2026-11-03 比武发现）。
- 沙盒里 jsDelivr 403，库是 npm pack 下来放进 `lib/` 的。

## 踩过的坑（0.2.0）

- 值的格子不能用 `<span>`：docx-preview 生成 `p.样式名 span{font-size}` 规则，会盖掉外层 run 的字号 → 用自定义元素 `<q-v>`。
- 合并边框的表格，格子边缘就在线正中，按「往里收半根线」画会变双线。
- 分组判断要有一列像单号；不然工资条「月份」「备注」相同的几行会被并起来（复赛时撞上过）。
- WOFF 解压用 `DecompressionStream("deflate")`（zlib 头），同一个 `QSans` 多块字体要给 `unicodeRange`，不然浏览器只用最后一块。
- Playwright 无头浏览器里 blob 下载的 `suggestedFilename()` 总是 `download`，旧版也一样，不是我们的 bug。

## 踩过的坑（0.4.1）

- 顶栏原来 72% 透明，滚动时下面的分段控件字透上来跟 Doc Batcher 叠在一起；底色提到 98%。提示条用 `left:50%` + `translateX(-50%)` 定位，可用宽度只有半屏，英文提示被折成两行，加 `width:max-content`。
- 沙盒里的 Inter 开了 `font-variant-numeric:tabular-nums` 会把连字符也撑成等宽（One-Slide 看着像 One - Slide）：等宽数字只给行号、计数、进度，表格、文件名、预览标题不开。
- 设计规范的字体栈 PingFang SC / Microsoft YaHei UI 在 Segoe UI 前面，Windows 英文界面会拿雅黑的西文字形；`html[lang="en"]` 换一套西文在前的栈。
- 西文字体刚加上时 500 份 PDF 从 8 秒涨到 12 秒：慢的不是切子集，是每份多出来的四次压缩（`CompressionStream` 绕 Blob 的写法每次有固定开销）。换成直接写 writer 以后反而比原来快一倍。
- 后台线程字体键只认一个字母（`fk[0]`、`NAME[w[0]]`），新加的字体族名必须是单个字母（l、t）。

## 踩过的坑（0.4.0）

- 英文按钮、副标题比中文长一截：`text-wrap:balance` 让大标题、副标题、丢文件那两句折得匀；「没模板？在线写一个」两组各自 `nowrap`，窄屏整组换行，不再把「Paste it」单个甩到下一行。
- 中文副标题加了 balance 以后会在词中间折（「一行｜抄一份」），中文那几句加 `word-break:keep-all` 只在标点处折。副标题用 `\n` 分句（`white-space:pre-line`），电脑上第二句单独一行。
- 模板文件卡底下一行「Sample · Landscape · 5 placeholders」在 390 宽被截；英文改叫 field（Word 邮件合并本来就叫 merge field），不截了。
- 英文示例 HTML 写在模板字符串里，`${{Total}}` 会被当成 JS 插值，写成 `\${{Total}}`。
- 按钮折没折行要只量字（TreeWalker 量文字节点），连图标一起量会把「图标 + 字」误判成两行；编辑器工具栏本来就横着滑，出界不算。

## 踩过的坑（0.3.0）

- Playwright `setFiles(本地路径)` 文件名是中文时不触发 change（沙盒里复现），测试里用 `{name, mimeType, buffer}` 内存文件。真用户走系统文件框不受影响。
- `autoMap()` 记住的「留空」是 -2，后面的「名字包含」匹配要写 `c===-1` 才跑，写 `c<0` 会把 -2 覆盖掉。
- 深色模式 `--bg-group` 也是纯黑，空状态的丢文件块要用 `--card` 色（`--dz`）才看得见。

## 踩过的坑（0.2.1）

- 从终端输出里复制代码会把私用区字符（空位记号 \uE000–\uE002）吞掉，记号一律写成 `\uE000` 转义。
- docx-preview 的制表符宽度算不准（编号后空一大截），而且渲染完还会异步改行内 `word-spacing` 和 `font-size`，要用样式表 `!important` 压住。
- inline-block 撑宽会把整行撑高 13px，改用 padding-left。
- python-docx 默认模板主题字体是 Cambria + 宋体（Hans），Word 在中文系统显示宋体；0.2.1 起照实出宋体，发票套 PDF 从黑体变宋体，体积和时间都涨一点。
- Noto Serif SC 从 @fontsource/noto-serif-sc@5.3.1 拿（woff，跟黑体一样的切法）；霞鹜文楷从 lxgw-wenkai-webfont@1.7.0 拿 woff2，用 fontTools 转 woff 并删掉 AAT/GSUB/GPOS 表（浏览器不需要，体积小）。
