# 包租僧 · 设计记录（0.3.0）

给接手的人看。一个 `index.html` 管全部；同目录还有 `manifest.webmanifest`、`sw.js`、`icon.svg`（favicon，跟总舵首页卡片同图形同色）和从它出的四张 PNG（`bench/icons.js` 重出）。

## 结构

- `index.html`：样式 + 一段 IIFE 脚本。脚本顺序：
  1. `T`：**界面上所有字都在这里**，改字只改这一处。动态的字是函数。
  2. `MODEL-START … MODEL-END`：纯函数，不碰 DOM：`span / calc / parseRoster / makeDemo`。
  3. 状态与存储（`S`、`St`、`UI`），`Ops`（所有改账的入口）。
  4. 撤销（`snap`/`undoable`：改账前存一份，提示条给「撤销」）；备份 / 导回（也能整页丢文件），结清后提示存备份。
  5. 视图：首页、单套房、总账；底部弹出的表单（sheet）。
  6. 事件、路由（`#h-xxx` 进房子，`#ledger` 总账）。
- `window.__bzs` 只暴露纯函数给测试用，不暴露数据。
- `sw.js`：先上网拿新版，没网用上次缓存的外壳。只缓存页面文件，账不在缓存里。
- `bench/`：比武材料（场景、独立答案、真流程脚本、步骤账 `steps.js`、测快 `speed.js`、撤销检查 `undo-check.js`、截图 `shots-0.3/`、结果）。

## 数据

一个账本 = `{ houses: {id: house}, order: [id] }`，存 `localStorage['baozuseng.v1']`（键名沿用 0.1，字段只增不改，0.1 的账直接能读）。

```
house  { id, estate, unit, self, byRoom, created:'YYYY-MM', demo?,
         tenants:[person],            // 花名册：没碰过的月份照它生成
         fixed:[{id,name,amt}],       // 每月固定支出
         months:{ 'YYYY-MM': month } }
person { id, name, room, rent, share, from?, to? }   // from/to 'YYYY-MM-DD'，空=不限
month  { elec, self, rows:[person + {paid, owe?}], exp:[{id,name,amt,fixed}] }
```

- **旧月冻结**：一改账，`freeze()` 把开张月到本月都实体化，之后改本月不会带歪旧月；改本月的房租/名字同时改花名册，下个月跟着走。
- **住的日期是人的属性，不是某个月的**：改入住/住到，`place()` 会对所有已实体化的月份重排——住着的补上（新人只补到当月及以后，有入住日的按入住日往前补），不住的拿掉，日期同步。
- 界面小状态 `localStorage['baozuseng.ui']`：`a2hs`（主屏引导关了）、`asked`（哪个月提示过备份）、`lastBk`（上次备份日）。

## 算法（全部整数分）

- 天数 `span(x, m)`：入住日、住到那天**都算**；当月天数 D。
- 房租：住满 = 月租；否则 `round(月租分 × 天数 ÷ D)`。
- 电费按「人天」平摊：总人天 = 各房客当月天数之和 + 二房东自住时 + D。
  分摊的人付 `round(电费分 × 他的天数 ÷ 总人天)`。包电的人那份、二房东自己那份、凑整的零头都归二房东（`eatC`）。
  所有人住满时等于老算法 `电费 ÷ 人头`，0.1 的旧账数不变。
- 一间两人：按人算，各写各的月租，电费各算一个人头。按房间看时显示这一间合计。
- 收入 = Σ(房租 + 电费)；支出 = 电费账单 + 其他支出；净赚 = 收入 − 支出。
- 欠租：本月标欠 `owe`，以后各月显示「之前欠」，点「还清了」清掉。
- `Math.round` 是 .5 进位；分子分母都是小整数，浮点不会把 .4999 算成 .5（比武 151 处核对 0 差）。
- 名单粘贴能认 `11号入住`、`住到20号`、`20号搬走`，日期落在当前看的月份。

## 存储与不丢账

数据不出这台设备，没有服务器，没有账号。

1. **放到主屏幕**：第一次在手机上打开就有一张一行的卡片（空账本时在按钮下面，有账时在标题下面），不关也不挡事。iPhone 教「分享 → 添加到主屏幕」（放上主屏的网页 iOS 不会 7 天清数据）；安卓有安装事件就直接一个按钮。关掉就不再出现；已在主屏打开不出现。
2. **持久存储**：有了自己的账就调 `navigator.storage.persist()`；结果显示在页脚（「已上锁」或「记得存备份」）。
3. **备份**：每月所有房子都收齐、电费填了，弹一次「存备份」（每月只弹一次，示例账本不算）。手机上走分享面板（iPhone 选「存储到文件」），电脑上直接下载 `包租僧备份-日期.json`。首页「账本」组里随时能存，超过 31 天没存会标黄。
4. **导回**：首页或空账本点「导回备份」→ 选文件，或者把文件丢进页面任何地方。这台没账就直接导入；有账也直接换，提示条给「撤销」（0.3.0 起不问「确定吗」）。
5. Google 网盘多机同步：按拍板，等 Song 要了再做，代码没写。

## 0.3.0 去掉的步骤（怎么做的）

- **全屋账单一条**：`billsAll(h, c, m)` 出一条消息——抬头、电费怎么分（有人按天折才提）、每人一行「名字 应交（住几天，房租 + 电费 + 之前欠，已收）」。电费按钮下面就是主按钮「复制账单」。单人账单还在房客浮层里。
- **都收了**：没收的 ≥ 2 位时，房客列表里出一行「都收了」，`Ops.allPaid` 只动「没收、也没标欠」的人；提示条给撤销。
- **建房 + 贴名单一张单子**：`rosterEditor()` 是贴名单的公共件（新建房子浮层和「粘贴名单」浮层都用），认出来的人列成卡片当场改；点「建好」前没跑完的解析先跑掉，用户改过的卡片不会被重解析冲掉。
- **单套房直接进**：启动时只有一套自己的房（没有示例），路由直接进那套房（`history.replaceState`），左上角「房子」回总览。
- **不问「确定吗」**：删房子、删房客、删支出、清示例、导回换账，一律先做，`undoable(msg, snap())` 提示条 6 秒内能撤。
- **电费打错**：框下一句人话，分摊和「复制账单」先藏起来、上面的数变淡，不让拿错数发账单。

## 长相（照 _ops/设计规范.md）

- CSS 变量原样抄规范；主色 `--accent` #cc2c7c（#E2418C 白字对比度不够，加深），深色 `--accent` #ff5ca8、按钮底 `--accent-fill` #d63384。
- 圆角：卡片 18、按钮 12/14、输入框 10、小标签 8；间距 4 的倍数；只用系统字，字重 400/600/700。
- 电脑宽（≥ 960）房子页两栏 `.two`，顶栏 `.nav.wide` 跟内容对齐。

## 改字、改版本

- 改字：`T`。改版本：`VERSION` 常量 + `sw.js` 里的缓存名（不改缓存名，老用户也会走网络优先拿到新版，只是旧缓存多留一份）。

## 已知边界

- 「删掉这条」只删当月这行，删本月时连花名册一起删。
- 改过去月份的人加日期，会把他补进以后各月（这是设计：人是连续住的）。
- 只在 Chromium 里真跑过；iPhone Safari 的分享面板存文件、主屏模式没在真机上试。
