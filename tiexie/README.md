## 加秘籍

两条路，改哪边都行：

- 手机上：iPhone 版「铁屑江湖」每页右上角「改」，新开一本在目录最底下。改完经大管家推上来，网页跟着变（接口见 `ios/大管家接口.md`）。
- 直接改 `data.json`（2026-11-24 起秘籍从 `index.html` 搬到这里，网页、app、大管家三家都读这一份）：
  - 写法固定：UTF-8、不转义中文、缩进 1 个空格、结尾一个换行（Python：`json.dumps(d, ensure_ascii=False, indent=1) + "
"`）。
  - `books`：一本一条。`id` 用英文小写（就是网址 # 后面那段），`category` 填 `baodian` 宝典 / `daofa` 刀法 / `buzhen` 布阵图 / `bingqi` 兵器谱，`body` 是正文，`img` 是封面图路径（空着就用代码画一本蓝皮线装书），`modified` 是改的时间（ISO 8601，带 +08:00，改了就更新它，不然手机上那份可能不认）。
  - 正文自动排版：大写字母加数字、`#`、`%`、`(` 开头的行算代码，行尾中文括号里的字挪到下一行当注释；`【…】` 和「第X式…」（不带冒号）是小标题；冒号前 24 个字以内加粗；空一行是分段。
  - 布阵图：先在 `sets` 加一个大标题（比如 `{"id": "svm10", "title": "VM-10", "img": "", "modified": "…"}`），图纸那本 `category` 填 `buzhen`、`setId` 填大标题的 id，详细图片按顺序写进 `plates`。图片放 `img/`，封面长边 1000 像素左右，详细图长边 1600 左右，JPEG。
- 改完推到 main 就上线（GitHub Pages 有约 10 分钟缓存）。
