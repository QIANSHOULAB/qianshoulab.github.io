## 英寸照妖镜

- 认字：苹果本机的 Vision（`VNRecognizeTextRequest`，accurate，英文 + 简体中文），网页版的 PaddleOCR 不搬，不用下 30 MB 模型，照片不出手机。
- 扶正：先用投影法量歪了几度（缩到 800 宽，比周围暗一截的像素算墨、阴影不算，试一圈角度，横向投影最尖的那个就是平的），转平以后四个方向各让 Vision（fast）看一眼，认出字最多、最有把握的方向是正的。透视交给出图那步的四角矫正，跟网页版一样。
  - 一开始用 Vision 字框四角量歪，透视、模糊那几张量错（模糊透视那张量成 18°），改成投影法：本机 8 张假表都对上真值（歪 7° 那张量出 -7.0°，网页版自己是 -6.2°）。
- 读表、对账、换算、改数：网页版 `MIRROR` 原样搬（`YingCun.swift`），JS 的对象键先后、稳定排序、`toFixed` 都照着来。
- Vision 跟 PaddleOCR 不一样的两处，补了：
  - 网页版只认要的那几列，Vision 一次全认：表头下面不在 尺寸/下差/上差/余量/LCL/UCL/标号 列里的字抹掉（实测值、结果栏不掺进来）。
  - Vision 有时把「DIMENSION 尺寸」认成乱码（毫米那张认成「DIENRJ」）：表头那排有 LSL、USL 却没有 DIMENSION 时，把 LSL 左边那个字框当 DIMENSION。只在网页版读法读不出表时才用。
- 长相：网页版那面照妖镜（八卦镜框、外圈法阵、藤蔓、镜光）是网页自己画出来、用 Playwright 截的透明图层（`zhaoyao-*.webp`），镜面在 SwiftUI 里画；外圈平时每秒 5°，照妖时 70°，一按甩到 260° 再慢下来，照妖时镜面扫光，跟网页版一样。
  - 两套风格：网页版是深色工单皮，铁屑江湖是宣纸。我替你定了：页面照铁屑江湖（宣纸底、毛笔标题、墨框按钮，跟另外两个工具一个样），镜子挂在一块墨色镜龛里（深色圆角框），藤蔓的蓝光在黑底上才亮，放到宣纸上会发灰。网页版截图 `docs/122-网页照妖镜-390.jpg`，app 截图 `shots/`（发版时 CI 截，镜龛里那面镜子 + 下面真跑一张假表的结果）。

## 铁件点钞机

- 界面照 0.5.0 搬：机身面板（螺丝、六角图标、铭牌、状态灯 待机 / 点钞中 / 完成 / 卡钞了）、绿色七段数码管、取景器（没拍时演示托盘自己点数）、浮在底下的快门玻璃（左相册、中间紫色滚花旋钮「拍」、右设置）。数码管点钞中一段一段转圈，数完从 0 跑到总数，圆点一排一排亮。放在铁屑江湖里也是它自己的夜色群青脸。
- 大脑换成大管家，Gemini 一律不用：拍完缩到大管家看图的尺寸（照 `luru.resized_size`，5 组尺寸跟 Python 算的一样），寄 `tx-count`；先到 `first` 出数和圆点（状态行「复查一遍，专抓躲在后面的」），再到 `final` 补第二眼，补的点柠檬绿圈、状态行「复查揪出 N 个漏网的」；两封都没到之前数码管一直转；90 秒没第一封说「大管家没回，再拍一次？」；第一封到了第二眼 200 秒不来就照第一遍的数。
- 大管家不在、没配对：直说，不寄、不排队，照片不留（「大管家不在（上次在线 HH:MM），这盘先自己数。」「还没跟大管家配对：设置 › 粘贴配对码」，下面一个「去设置里配对」）。
- 手改：点圆点删、点空处补（落在算的盒子里，不在就给主盒），旁边「手改 +n −n」；每盒「不算 / 也算上」；主盒没拍全标黄。
- 存图：照片 + 圆点 + 底下一块数码管面板（总数、件、手改、铭牌、时间、大管家数的），弹系统分享面板。
