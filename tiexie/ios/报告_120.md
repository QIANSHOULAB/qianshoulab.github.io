- **app 本体 `tiexie/ios/`**：SwiftUI + XcodeGen，`lab.qianshou.tiexie`，桌面名「铁屑江湖」，URL scheme `tiexie`，iOS 26 起，0.1.0。不带扩展，不用 App Group、iCloud、推送；相机、相册写了说明。
  - 长相照网站：宣纸底、双线版框、目录 + 封面、背景招式小人、印章；毛笔字 Ma Shan Zheng、正文 Noto Serif SC 整套打进包（CI 现拉，OFL），只有宣纸亮色一套。

  - 正文排版照网站 `typeset()`：代码行、行尾括号注释挪下一行、`【…】` 和「第X式」当小标题、冒号前加粗、空行分段。
  - 离线：`data.json`、`img/` 打进包当底子；打开、回前台、联网时拉网上的 `data.json` 和缺的图，断网看本地。
- **每页能改**：右上角「改」：标题、正文、封面（拍照或相册，也能去掉）；布阵图的图纸加详细图、删、拖着排；每栏末尾「新开一本」，布阵图「新开一个大标题」；扔之前问一句（扔大标题连图纸一起扔，会说几张）。先存本地，再进发件箱。照片缩好再寄（封面长边约 1000，详细图约 1600，JPEG，`img/<id>-<SHA-256 前 8 位>.jpg`）。

- **工具箱**：`Tools/<工具>/` 一个工具一个文件夹（界面、算法、字、单测、README），共用的在 `Shared/`，注册表 `Tools/Registry.swift` 一个工具一行。CI 每次「拆掉工时榨汁机」再编一遍、跑一遍测试，验「删一个工具 = 删文件夹 + 一行」。
  - 角度算距离：弦长 2R·sin(Δθ/2)，不分 X/Y，照 gongshi `tp/index.html` v0.5.5。
  - 工时榨汁机：默认扣 10:00–10:10、11:30–12:10、15:00–15:10、18:00–18:30，20:30 下班，跨天跳到次日 08:15，重叠只扣一次；休息表能改、加、删、恢复默认，存在 app 里。

## 单测（CI 全过）

- 加密：一叶笺接口 v2 那段对照密文能拆开；手机 ⇄ 电脑来回；信封形状；信箱号只露前 6 位。
- 配对码三种写法都认，一叶笺的码不认（假配对在代码里现生成）。
- 合并：新的赢；有待寄改动留本地；别处删了跟着删；寄到了但 Pages 还是旧缓存时不被旧的盖回去；删了的不从旧缓存长回来。
- 发件箱：杀进程不丢、同一条只寄最新一版、2 分钟没回信重寄、`ok` 清掉、`stale` 当寄到、失败留着、只带网上没有的图。

## Song 装机

0. 先回 LiveContainer 本体：Safari 打开 `livecontainer://livecontainer-launch?bundle-name=ui` → Open → 弹 “switch to LiveContainer?” 点 OK。底下是四格 Sources / Apps / Tweaks / Settings 就对了（SideStore 是五格，别认错）。
1. LiveContainer 里 Sources → + → 粘贴 `https://qianshoulab.github.io/apps.json` → Add
2. 点铁屑江湖 → Install
3. 回 My Apps（本体底下那格 Apps）打开
4. 先在 Telegram 里复制大管家发的配对码，再点右上角齿轮 → 粘贴
