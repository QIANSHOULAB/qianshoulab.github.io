# 铁件点钞机

拍一盘工件，大管家数，数码管跳出总数，照片上每件一颗圆点；数错的点一下就改。

- 搬自：QIANSHOULAB/gongshi `draft-count` 分支 `count/index.html` 0.5.0（字在 `strings.js` 的 zh.count）。施工单 122。
- 长相照 0.5.0（Song 11-04 给的三张参考图定的）：夜色群青底、机身面板（四颗螺丝、六角图标、「千手院出品 / 铁件点钞机」、状态灯 待机 / 点钞中 / 完成 / 卡钞了）、绿色七段数码管、取景器（没拍时演示托盘自己点数）、浮在底下的快门玻璃（左相册、中间紫色滚花旋钮、右设置）。放在铁屑江湖里也用它自己的脸。
- 大脑换成大管家（Song 11-04：Gemini 数错盘子；11-06 下架；122：「大管家认那个照片，然后去数数量」）。Gemini 一律不用，没有退路。
  - 拍完缩到大管家看图的尺寸（pc-butler `handheld/luru.py` 的 `resized_size`：长边 2576、28 像素一格、最多 4784 格），JPEG 90，寄 `tx-count`（接口见 `tiexie/ios/大管家接口.md`，大管家那头是 121 的 `handheld/tiexie/count.py`）。
  - 回两封信：`stage: "first"` 先出数和圆点；`stage: "final"` 补上第二眼，补的点柠檬绿圈，状态行「复查揪出 N 个漏网的」。两封都没到之前数码管一直转；90 秒没第一封说「大管家没回，再拍一次？」；第一封到了第二眼 200 秒不来就照第一遍的数。
  - 大管家不在、没配对：直说（「大管家不在（上次在线 HH:MM）」「还没跟大管家配对：设置 › 粘贴配对码」），不寄、不排队，照片不留。
  - 信走 app 本体的信箱（`App/Butler.swift` 的「工具箱的一次性的信」：寄一封、按请求 id 收回信，不进发件箱、不重寄、不存盘）。照片只寄给自己的大管家，不进日志。
- 手改：点圆点删掉，点漏掉的件补一个（落在算的盒子里，不在就给主盒），数字跟着变，旁边写「手改 +n −n」；每盒「不算 / 也算上」；主盒没拍全标黄提醒看边上。
- 数完数码管从 0 跑到总数、圆点一排一排亮（减少动态效果时直接出数）。
- 存图：照片 + 圆点 + 底下一块数码管面板（总数、件、手改、铭牌、时间、大管家数的），弹系统分享面板（能存相册）。
- 单测：`Tests/DianChaoTests.swift`：假大管家照接口加密回两封信，走出数、补点、手改、不算 / 也算上、超时、没配对、大管家不在、大管家说没数成；缩图跟 `luru.resized_size` 对了 5 组。
- 文件：`DianChao.swift` 算法和收信状态，`DianChaoPost.swift` 寄给大管家那根线和一盘的流程，`DianChaoArt.swift` 数码管、圆点、存图、演示托盘，`DianChaoStrings.swift` 字，`DianChaoView.swift` 界面。
