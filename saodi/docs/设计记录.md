## 关键决定

- **Python + pywebview + PyInstaller 单文件 exe**。核心逻辑纯标准库，能在 Linux 沙盒里测；界面是网页，跟总舵其他罗汉一个长相。没拿到录入僧（QIANSHOULAB/bangong）的仓库权限（这趟没有 add_repo），打包和冒烟是自己按同思路写的，以后对一下 bangong 的做法统一。
- **两段式改名**：先全部改成同目录临时名 `.saodi-xxxx-N.saodi-tmp`，再改成目标名。a↔b 互换、只改大小写（NTFS 不分大小写）都不会撞。第二段失败会改回原名；极端情况卡在临时名，账本里有，撤销能救。
- **绝不覆盖**：POSIX 上 os.rename 会覆盖，所以先查；Windows 天生不覆盖。目标被占就自动加 ` (2)`。预览阶段已经避让，执行时又有人放了同名文件也会再避让。
- **绝不删除**：程序里唯一的「删」是 `fsutil.to_trash`（Windows 用 SHFileOperationW + FOF_ALLOWUNDO 进回收站）。撤销分文件夹时只 rmdir 自己新建、且已空的文件夹。
- **非法字符换全角**：`: ? * " < > | / \` 换成 `： ？ ＊ ＂ ‹ › ｜ ／ ＼`，CON/NUL 等保留名前面加 `_`，单个名字超 255 字节截主名保扩展名。
- **撤销按批**：每批一个 json 账本，批次 id 带微秒保证排序 = 时间顺序（踩过坑：同一秒两批，撤错批）。撤销时用户已经挪走的文件跳过并报出来；原名被新文件占了就退成 `原名 (2)`。
- **盯文件夹用轮询**不用系统通知：网盘同步盘、U 盘、网络盘都靠得住。文件「落稳」= 两次看大小和修改时间都不变 + Windows 上独占方式能打开（`fsutil.in_use`）。`.crdownload/.part/.tmp/~$` 不碰。被占用挪不动的不记成「见过」，下一轮再试，同一个文件只报一次。0.3.0 起开机自启、关窗进托盘，「见过的」存盘，程序关着时来的下次一开就补分（见下面 0.3.0）。
- **下载**：中文网址/中文域名先转成 %xx / punycode（踩过坑：urllib 只认 ASCII）。文件名优先 Content-Disposition（含 filename*=UTF-8''），没扩展名按 Content-Type 补。.part 残片在就带 Range 续；服务器不支持 Range（回 200）就从头。404/403 直接判失败不重试。0.2.1 起：断线前收到过数据 → 立刻续、不算重试次数（上限 30）；回了响应头没给数据就断 → 立刻重连、算一次重试；连不上 / 5xx 才退避 0.3、1、3、6 秒，共重试 4 次。
- **自动更新**：只做「提示有新版 + 打开介绍页」，读 `https://qianshoulab.github.io/saodi/version.json`。没做静默替换 exe（单文件 exe 自替换要额外的更新器进程，毛坯不值）。
- **发版**：改 `saodi/app/saodi/__init__.py` 的 VERSION 和 `saodi/version.json`，推 main；工作流打 tag `saodi-v版本号` 的 Release（`--latest=false`，不抢别的罗汉的 latest）。介绍页下载链接由 version.json 推出来。

## 0.2.0（2026-11-03，Song 拍板：签名先不买、盯文件夹不常驻、改名高级来源和盯梢动作都补）

- 改名新增「模板」规则 `{"type":"tpl"}`：变量 原名 文件夹 大小 修改日期 拍摄日期 相机 宽 高 歌手 标题 专辑 音轨 年份 序号。读不到的变量留空、提示「有的信息读不到」，留空后多余的连接符自动收拾（`{歌手} - {标题}` 缺歌手 → `标题`）。全部变量都空就不改名。
- 国内老 MP3 的 ID3 标成 latin1 实际是 GBK：有高位字节先按 GB18030 解。
- 分文件夹方案新增 `action: copy`（复制一份，原件不动）、`unzip: true`（压缩包解到原地同名文件夹，压缩包本身照规则走）、规则 `by: content`（内容里有关键词）。盯文件夹同样生效。
- 执行器多了「第零段」：复制、解压先做（要读原件），再做挪动的两段式。撤销时复制品、解压出来的文件夹进回收站；复制品大小变了（用户改过）就不碰，报「复制品被改过」。
- 盯文件夹复制模式踩坑：原件还在，下一轮会被当新文件再复制 → 处理完把留在原地的原件记成「见过」。
- 没做：rar/7z（要第三方库）、PDF 中文内容（字形编码，要 pdf 库）、OGG/WMA 标签、视频时长。

去掉的没必要步骤（步骤账在比武报告「0.3.0 复赛」）：
- **每次手动点整理 → 盯着「下载」自己分**。第一次打开（含从 0.2.x 升上来的第一次）`Api.boot()` 把「下载」加进盯着的单子（分法默认「按类型」），顶上说一句「「下载」交给贫僧了」，同一行有开关（一下能关）、「旧的 N 个也分了」（现有那摊动不动是人的判断，留一下；一批，能整批撤销）、「知道了」。`cfg.v03` 记着说过了。
- **每天开程序 → 开机自启 + 托盘常驻**。第一次跑写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\QianshouSaodi = "exe" --tray`（只当前用户，不要管理员；「盯着」页一个开关能关，关了不再自己写回去；exe 挪了地方下次开会改指向）。`--tray` 起来不开窗口。关窗口 = 收进托盘（第一次收时冒个泡说一声），托盘菜单：打开戒尺僧 / 盯着「下载」（勾）/ 退出。窗口收着时自动分完冒个泡（「分完冒个泡」开关），窗口开着时界面底下出提示条，带「撤销」。
- **只开一个**：`SAODI_HOME/instance.port` 记着本机端口；第二个实例连上去说 `saodi show`（`--tray` 起的说 `saodi tray`），对方回 `ok` 就自己退。防的是两个进程同时盯一个「下载」抢文件。

- **改名模板每次重配 → 记住**。改成功一次就记 `cfg.rename_last`（下回打开自动回来，左上「照上回的改法 · 清空」）和 `cfg.rename_recent`（最近 6 套，一点换，× 删）。0.2 的「存成常用」（要弹系统输入框起名字）去掉了，旧的常用照样认。

## 踩过的坑

1. Windows 控制台默认 cp1252，pytest 打印中文就崩 → 工作流设 `PYTHONUTF8=1`。
2. NTFS 目录列表里的文件大小对「还开着写」的文件是滞后的 → 盯梢用 `os.stat` 取真实大小，再用独占打开判断有没有人在写。
3. 同一秒内的批次按 id 排序会乱 → id 带微秒。
4. pywebview 会把 js_api 对象的公开属性都暴露给 JS，窗口对象挂上去会递归 → Api 里一律用下划线属性（`_window`）。
5. 界面 JS：`head()` 里局部变量叫 `chip` 跟全局函数 `chip` 重名，TDZ 报错白屏 → 端到端测试抓到的，改名 `fc`。
6. （0.3.0）pywebview 的 `window.destroy()` 在 Windows 上走的是 `Form.Close()`，会进 `closing` 事件；关窗收托盘那个处理返回 False 就把「退出」也拦了 → 退出前先设 `quitting`。
7. （0.3.0）pystray 不看 `Shell_NotifyIcon` 的返回值，系统托盘没收它也照样说 `visible=True` → 托盘冒烟里自己再问一遍，CI 上只记不判。
8. （0.3.0）Playwright 量「点下去到提示条出来」：提示条后面紧跟着画 1000 行大表时，`wait_for_selector` 要等大表画完才看得见提示条，墙上时间虚高 → bench 另记页面里 MutationObserver 的毫秒数，两版同法同机比。
9. （0.3.0）路径用 `direction:rtl` 从左边省略时，开头的 `/` 会跑到末尾（双向文字规则）→ 前后各加一个 U+200E。
10. （0.3.0）`json.dump(..., indent=1)` 写文件走纯 Python 编码，1512 个操作的账本一遍 8.6 ms；`json.dumps` 不缩进走 C 编码 3.0 ms。
