## 0.3.0 自己定的（三轮：去掉没必要的步骤 + 好看；没人可问，按最合理的办法）
- 0.2.0 那条「盯文件夹不常驻」（设计记录里记的 Song 拍板）这回被盖过：三轮施工单（Song 11-03 17:02「开机就在岗，有事才叫人」）和队长单子都要默认在岗、开机自启、托盘常驻。「盯着」页一个开关能关开机自启，关了不再自己打开。

- 开机自启写当前用户的 Run 键（不要管理员，不碰别的用户）；第一次跑默认开。关窗口 = 收进托盘，退出在托盘右键；第一次收进托盘冒泡说一声。
- 自动分完：窗口收着就冒个泡（「分完冒个泡」能关），窗口开着就出提示条，带「撤销」。没做按文件逐个弹窗。
- 0 字节的文件一律等（Firefox 先放占位）；带 .part/.crdownload/.aria2/.xltd 兄弟的等；人挪回来的、撤销回来的不再分（认文件身份）。
- 批量下载的「下载 N 个」那一下留着：一坨文字里可能夹着退订、确认这类一点就生效的链接，下哪几个是人拍板；「存到」「文件名」记住，第二次不再选。
- 「存成常用」（弹系统输入框起名字）去掉，改法改成功一次就自动记，最近 6 套一点换；0.2 存的常用照认。
- 名字这回仍叫扫地僧：改名戒尺僧是四轮（0.4.0）的「先办」，不在这趟。
- 一文件夹 ≥ 80% 是照片（且 ≥ 5 个）时，分文件夹先勾「照片按拍摄月份」：按类型分等于全进「图片」；这个文件夹上回用过别的分法就照上回的。
