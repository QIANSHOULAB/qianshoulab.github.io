# 知客僧 · 设计记录（给接手的 Claude）

知客僧 = 千手院的邮件分拣罗汉：IMAP 盯邮箱 → 按规则认信 → 点选学来的字段抽进 Excel → 自动转发 → 草拟回复（只存草稿，绝不发）。
当前版本 0.4.1（2026-11-04 意见入口单：设置「关于」里一行「提意见」，介绍页页脚一个；点了打开写好开头的邮件）。
0.4.0：四轮：字。中文润色，英文从头写一套 Zhike · Inbox Sorter；默认英文、设置里 EN / 中文 切换并记住。
0.3.0：去掉没必要的步骤 + 好看（连上邮箱贫僧拟好规则、人只管收不收；开机就在岗；界面照 _ops/设计规范.md 重做）。
0.2.0：转发信认原信、同义标签、挡垃圾、PDF 附件、AI 兜底抽字段、自动更新、微软登录代码。
Windows 电脑程序，Python + pywebview（WebView2）+ pystray，PyInstaller 打成单个 `Zhike.exe`。

## 字段归纳（learn.py）怎么想的

- 用户在正文里选中一段 → 取同一行左边的「标签」（`订单号：`、`Amount Due:`），左边空就取上一行当标签（HTML 表格转文字常见）。
- 值的类型自动猜（金额/日期/编号/电话/邮箱/数字/文字）；类型决定值在哪结束。文字类型记右边是空格还是某个字符来截断。
- 同名字段再选一封，就多一种标签写法（`labels` 是列表，任一命中即可）。
- 有标签但新信里没找到 → 返回空，不瞎猜。没有标签 → 用「正文里第 N 个这种值」兜底。
- 进 Excel 时金额转数字、日期转日期，能直接求和/筛选。
- `suggest_fields` 把「标签：值」样子的地方虚线标出来，点一下就能收。

## 0.2 加的几样怎么想的

- **转发信**（`mailparse.forward_blocks`）：认「Forwarded message / Original Message / 转发的邮件 / 原始邮件 / Begin forwarded message」标记和
  `From/发件人 + Subject/主题/Date/发送时间` 信头块，取最里层。规则的发件人条件「外层或原信对上都算」，主题条件看外层和原主题。
  内置字段「发件人」「主题」记原信的。抽字段还是在整段正文上抽（原信就在里面）。
- **同义标签**（`learn.SYNONYMS`）：学到的写法都没对上，再试同一组里的别名（订单号/订单编号/Order #…、实付金额/应付总额/金额合计/Total…、
  运单号/快递单号/Tracking #…），标签后面冒号或空格都行。只对有类型的字段（金额/日期/编号/电话/数量）开，类型本身把关；左边紧挨字母汉字的不算
  （Subtotal 不当 Total）。
- **按内容认**（`rules.looks_like`）：发件人不限的规则（询价这种谁都会来），主题没对上但学过的字段抽到一大半（≥2 个）也算它的。限了发件人的规则不走这条，免得冒充信混进来。
- **挡垃圾**（`rules.junk_reason` + `engine._hold`）：发件域名和规则里的熟人域名差一个字母 → 挡；有推销/中奖/退订词**而且**学过的字段没抽全 → 挡
  （正常订单信脚注带「退订」不会被误挡）。挡下的信不进表不转发，记录里一键「放行」。规则里还有一行「含这些就不管」手动排除。
- **数量**：`200 箱`、`500 reams` 认成 qty 类型，Excel 里是数字、单位进单元格格式（`#,##0 "箱"`），能求和。
- **没年份的日期**：`11月5日` 按收信时间补年份（取离收信日最近的那年，12 月收到「1月3日」算明年）。
- **AI 兜底**：填了 Gemini 钥匙时，规则没抽到的字段问 AI；AI 给的值必须在正文里原样找得到，找不到不要。没钥匙照旧留空。
- **「没找到」一点就补**：收件里没抽到的字段是个按钮，点了再去正文里选，弹窗自动填好字段名和规则，等于给这个字段多一个样例。
- **PDF 附件**：pypdf 读文字（≤20 页、≤2 万字），接在正文后面「—— 附件 xxx.pdf ——」，能点选、能抽。转发/起草引用只用正文（`Mail.body`），不把 PDF 文字塞进信里。扫描件（图片 PDF）没有 OCR。
- **自动更新**：CI 先传 Zhike.exe 再传 version.json（版本、sha256、大小）。程序启动 8 秒后查一次、之后每 6 小时；有新版在后台下到 `Zhike.exe.new`，核 sha256，
  下次启动自动换上（正在跑的 exe 不能覆盖但能改名：`Zhike.exe → .old`，`.new → Zhike.exe`，带 `PYINSTALLER_RESET_ENVIRONMENT=1` 起新进程，新进程等旧 pid 退出后删 `.old`）。
  侧栏和设置里有「现在重启」。exe 所在文件夹不可写就退回「去下载」。CI 里有一步真换一次自己（`--update-probe`）。
- **微软登录**：见 `docs/微软登录注册.md`。代码和测试都在，差 Song 注册微软应用拿客户端 ID。

## 0.3 加的几样怎么想的（去掉没必要的步骤 + 好看）

步骤账和逐步对照在 bench/比武报告.md「0.3.0 复赛」。一句话：第一次用 121 步 → 15 步（QQ/163/Gmail 这种认得服务器的 115 → 9），
第二天来了新供应商 21 步 → 4 步；留下的每一步都是人在给信息（邮箱、密码、公司邮箱的服务器、转给谁）或拿主意（连上、收不收、看结果）。

- **第一次打开就是连邮箱**：一句话 + 两个框 +「用示例试试」（规范的空状态）。0.2 先进示例、再点横幅「连邮箱」跳到设置——多一下。
  回车就连；密码错就在密码框下面红一行，说怎么办。公司邮箱认不出服务器，服务器那块自己展开。
- **贫僧拟规则**（recommend.py，不问 AI，全在本机）：连上那一下 connect_new 拿最近 20 封当样例 → 每封找「标签：值」「标签  值」
  （HTML 表格转出来就是两个空格）→ 标签归成规范名（Order Number、订单编号 → 订单号；Amount Due、应付金额 → 金额；见 learn.CANON）→
  有运单号 = 物流、发票号 = 发票、订单号 = 订单、产品 + 数量 = 询价（询价谁都会来问：不限发件人，主题认 询价/报价/quotation/enquiry/inquiry，
  其余靠 0.2 的「按内容认」）。几家合成一条，列取几家都有的；都带附件就加「附件」列。认不出类型的：同一个公司域名 ≥2 封、字段一样也拟一条。
  - 不拿来拟：中奖/推广这种强推销词；退订/大促这种弱推销词而且字段不到 2 个的；跟别的来信域名只差一个字母的（数字顶字母那边算冒充，
    看不出就信来得少的那边）；订单/发票/物流只收公司发的（orders@、billing@、noreply@…或名字像公司），个人来信里提了个订单号不算。
  - 条件：每家「@域名」+ 这家主题去掉编号、日期、括号后的说法（订单确认 #SM-1 → 订单确认；【青石】11月服务费发票 QS-1 → 服务费发票）。
    有一家说不出共同的主题词就不靠主题。拟出来的条件必须认得这批信，认不得就放宽。
  - 比武那 10 封样例拟出的 4 条跟 0.2 比武里人手点出来的效果一样：200 封字段错 8 对 8、转发错 0 对 0（随机数 3：9 对 9、转发错 1 对 2）。
- **收不收**：一屏卡片，每张写着认哪些发件人、主题、抽哪几列（带样例值），开关默认开、名字能改、「转给」填了就转（不用再开转发开关）。
  底部一个主按钮「收下 N 条」。关掉的记住（config.dismissed），不再拟，来了新发件人才再问。收下给「撤销」（只撤规则，已经补办的那几封不撤）。
- **归进已有规则**：某一类已经有规则，来了新的一家（第二天来了白塔文具的发票）→ 拟成「归进「发票」」：加发件人、主题说法，
  字段多学一种写法（learn.merge_specs：老写法一个不丢——老样例的信可能已经不在手边，不能光靠重学）。
  收下那一下，**连上以后来过、当时没规则管的那几封也照办**（engine.catch_up：进表、转发、起草）；连上之前的旧信不动（从连上那一刻开始盯，0.1 定的）。
- **开机就在岗**：开机自启（注册表 Run，`"Zhike.exe" --tray`）改在头一个邮箱连上那一刻写（0.2 是第一次打开就写，没连邮箱也写），
  拟好规则那一屏当场说一句「开机自己跑：开着。关窗口贫僧躲进托盘接着盯」+「关掉」。设置里一个开关。老版本升上来、配置拷过来的：启动时有邮箱就补上，人关过就不动。
  --tray 起来不弹窗，自己连上次的邮箱、接着上次的进度收。刚开机网常常还没通：头 3 分钟里每 15 秒试一次（之后照旧 2→4→…→30 分钟）。
  头一回关窗口冒个泡「贫僧在托盘里接着盯」。托盘菜单多了「打开 Excel」。从托盘打开窗口时有新拟的规则，直接摆出来。
- **有事才叫人**（Api._tell）：托盘气泡只在要人管的时候冒：回信草稿备好了、拟了新规则、某个邮箱密码不对（只叫一次）、Excel 被占着（一回只叫一次）。
  进表、转发这种照常的事不吵（0.2 每封信冒一个泡，200 封冒 200 个）。只有这一轮来了没规则管的信才重新拟规则。
- **不问「确定吗」**：删规则、移除邮箱直接做，提示条上给「撤销」（移除邮箱时密码先在内存里留着，撤销放回凭据管理器）。改密码不弹 prompt，就地一个框。
- **界面**照 _ops/设计规范.md：变量原样抄，主色知客僧赭 #C2552A（白字 4.54:1）；深色里主色当字用提亮成 #F08A5D，按钮底不变；
  系统字，正文 15、辅助 13、注脚 12，页面标题 28；圆角 18/12/10/8；侧栏 220 分组列表（行高 44）；顶栏、底栏、浮层、提示条毛玻璃（压在滚动内容上的顶栏、底栏、菜单底色 98% 不透明：Chromium 里粘住的栏会按透明度透出底下清楚的字；点选弹窗 85%、提示条 96%）；
  系统 select / checkbox / prompt / confirm 全换成分段控件、iOS 开关、浮层菜单、撤销提示条；字段高亮只用主色浅底，推销「挡下」用 --doubt 黄底；
  图标 2px 线性圆头；尊重 prefers-reduced-motion。所有界面文字在 ui/strings.js（0.4 起托盘那几句也搬进去了，api.py 的 S 没了）。
- **图标**：zhike/icon.py 照总舵首页那张卡的 SVG 画（#F09A6B→#C2552A 渐变 + 白信封 + 赭色信封盖），16–40 像素那几档信封盖的线加粗一点；
  exe 图标就是窗口图标（pywebview 的 WinForms 从 exe 里取），托盘同一个，介绍页 favicon 用同一个 SVG。

## 失败路径（都有测试）

| 情况 | 行为 |
|---|---|
| 断网 | 这个邮箱退避 2→4→…→30 分钟；某封信的转发/草稿没干完，进 `retry`，下轮接着干，Excel 不重复写 |
| 密码错 | 这个邮箱停住（不反复撞密码，免得被锁号），其它邮箱照常；界面提示改密码 |
| 邮箱满 | 存草稿 `OVERQUOTA` / SMTP 552 → 记一笔，草稿仍留在知客僧里能复制，不重试 |
| AI 额度用完 / 钥匙错 / 连不上 | 退回模板回复，记录里标原因 |
| Excel 被占着 | 行进 `pending_rows`，每轮和「现在补写」时再写，顺序不乱 |
| UIDVALIDITY 变了 | 从现在重新开始，靠 Message-ID 防重复 |
| 自己转出去的信又回来 | 带 `X-Zhike` 头，直接跳过，防绕圈 |
| 配置文件坏了 | 改名 .broken.json，从空配置起，程序照样能开 |
| 推销信主题蹭上关键词 / 冒充熟人域名 | 挡下，记录里可放行 |
| 微软令牌过期 / 被撤 | 这个邮箱停住，界面「重新登录」 |
| 新版下载被篡改 / 不完整 | sha256 对不上就扔，不换 |
| PDF 坏了 / 加密 | 当没有附件文字，照常处理 |
| 注册表 Run 键不存在（新 Windows 用户、CI 机器） | 建出来再写（0.2 这里报错被吞，开机自启其实没写上） |
| 刚开机网还没通 | 头 3 分钟每 15 秒再试，后台线程到点就醒 |

CI：`.github/workflows/zhike.yml`，只在 `zhike/**` 变动时跑，windows-latest 上：pytest → PyInstaller → `Zhike.exe --selftest`（含 Windows 凭据管理器读写、PDF、转发信、拟规则）→ 窗口起来 20 秒不崩 → 自动更新换自己一次 →
**开机就在岗**（tests/win_boot_probe.py：照开机自启那样起 `Zhike.exe --tray`，查不弹窗、密码从凭据管理器拿、自己连上次的假邮箱、关机时来的新信进 Excel 并转发、旧信不重复、
Run 键写成 `"…\Zhike.exe" --tray`；再双击一次不起第二个、原来那个亮出窗口）→ 上传 Zhike.exe 和 version.json 到 release `zhike-latest`（`--latest=false`，不抢仓库别的罗汉的「最新发布」）。

发版办法：改 `app/zhike/__init__.py` 的 `VERSION`，推 main，CI 绿了就发出去了；老用户的程序最多 6 小时内查到、下好，下次打开换上。
下载地址固定：`https://github.com/QIANSHOULAB/qianshoulab.github.io/releases/download/zhike-latest/Zhike.exe`

## 踩过的坑

- aiosmtpd 当假 SMTP：AUTH 失败时会挂住 smtplib，换成自己写的最小 SMTP（fakeservers.py），exe 也少一个依赖。
- `os.replace` 被测试 monkeypatch 时会连 state.json 一起坏 → excel.py 里单独引用 `_replace`。
- IMAP `UID SEARCH UID N:*` 没新信时也会把最后一封带回来（RFC 规定），必须过滤 `uid > last`。
- 163/126 不发 IMAP `ID` 命令会报 Unsafe Login，`Imap.connect` 里有就发。
- pywebview 会遍历 js_api 对象的属性，Api 里有 store/engine 这种大对象 → app.py 里 `js_facade` 只暴露方法。
- GitHub release 附件名带中文会被改成点号，所以 exe 叫 `Zhike.exe`，窗口标题是「知客僧」。
- 这趟会话挂不上 QIANSHOULAB/bangong（录入僧电脑版），打包/自动更新没能照搬它的，按上面自己定的。以后能看到时对一下。0.2 精加工时还是读不到，自动更新按「version.json → 下 exe → 换自己 → 重启」自己实现。
- `email.policy.default` 解析很慢（建头部对象），200 封要 0.3 秒；0.2 换成 `compat32` + 自己解码头部，0.05 秒，436 封比对输出一字不差。
- 0.2 开发时踩的：`parse()` 里 PDF 循环变量叫 `name`，把发件人名字冲成了附件名。已改名并加了测试。
- PyInstaller 单文件 exe 起自己的新版本，要给子进程设 `PYINSTALLER_RESET_ENVIRONMENT=1`，不然它会去用旧进程解压的临时目录。
- 0.3 在 CI 上测出来：GitHub 的 Windows 机器（新建用户也一样）HKCU\…\Run 键不存在，`OpenKey` 报错，0.2 第一次跑时被 `except` 吞了，
  开机自启其实没写上。改成 `CreateKeyEx`。测试里开机自启是全用户共用的注册表，conftest 每个测试先清、测完放回。
- 0.2 的界面坑（步骤账走 0.2.0 时撞上的）：规则改名 450 毫秒后才存，这当口心跳（4 秒一次）把界面手里的规则换成后台的旧份，
  下一下改动（加条件）就把新名字冲掉。0.3：改名字、模板的 1.5 秒里心跳不去换。
- 拟规则的「标签  值」：HTML 表格转文字是两个空格隔开，0.2 的虚线建议只认冒号，所以拟规则另找两个空格那种，但只收像值的（编号、金额、日期…）或认得的标签，免得把正文当字段。
- 「Track it at https://…」会被虚线建议当成「it at https：//…」，0.3 起标签以 http 结尾、值以 // 开头的不算。
- 0.4 在 CI 上撞了三回 Windows 控制台的 cp1252：`subprocess.run(text=True)` 读 node 输出、`print(json.dumps(..., ensure_ascii=False))` 打中文都会炸。
  读要 `encoding="utf-8"`，打印要么转义、要么 `sys.stdout.reconfigure(encoding="utf-8")`。开机冒烟按窗口标题找窗口，默认英文以后标题是 Zhike，两种都认。
- 测试里 `Api()` 不设 excel_path 会写到真的「文档」文件夹（沙盒里是 /root/Zhike/Zhike.xlsx）：写表的测试一律先把路径指到临时目录。

## 0.4 加的几样怎么想的（字：中文润色 + 英文一套）

- **字只放一处**：`ui/strings.js` 里 `STR.en` / `STR.zh`（界面 + Python 那边要说的）、`SITE.en` / `SITE.zh`（介绍页）。Python 用 `zhike/text.py`
  按行读这个文件（键不加引号、值双引号、注释单独占行，这是写法规矩），跟浏览器里 node 算出来的一字不差（test_v04 对过）。英文单数用 `键_1`（n 为 1 时）。
- **默认英文，第二语言中文**（Song 11-03 22:19）。不跟 Windows / 浏览器语言走。设置里「语言」一行 EN / 中文；第一次打开那屏（还没侧栏）右上角也有一个，
  不然中文用户连上邮箱之前切不了。选了存进 config.json 的 `settings.lang`，下次打开直接是这套；窗口标题、托盘提示和菜单（pystray 的字是现取的函数）跟着换。
  **0.3 升上来的老用户**（config 里已经有邮箱、没有 lang）：接着中文，免得一升级满屏换了字——这是我定的，写进报告了。
- **跟着语言走的**：界面、托盘、气泡、新规则的名字（订单 ↔ Orders、发票 ↔ Invoices、物流 ↔ Shipping、询价 ↔ Quotes）和规范列名
  （订单号 ↔ Order #、金额 ↔ Amount、到期日 ↔ Due date……，进 Excel 就是表头）、内置列（收到时间 ↔ Received……）、默认回信模板、
  转发信头（转发的邮件 / Forwarded message）、Excel 默认文件名（知客僧.xlsx ↔ Zhike.xlsx；还没写过时切语言跟着换）、示例（中文一套信、英文一套信）、
  微软登录回来那页、更新说明。**不跟着走的**：已经收下的规则名、列名（Excel 里的表头不能说改就改）；用户的信本身照原样。
- **内部认法不变**：拟规则时字段、类型一律按中文规范名认（`learn.canonical`），交出去才换成当前语言的叫法；英文规范名都在同义词表里，所以
  `canonical("Order #") == "订单号"`。中文时收的「发票」，切英文后来了新的一家照样「归进发票」（test_v04）。拟稿的号跟语言无关，「不要」过的切了语言也记着。
  英文那套比武：200 封字段错 8、归错 0、转发错 0，跟中文一样（`run_zhike_en.py`）。
- **模板占位**：`{称呼}` / `{name}` 都认（还有 `{发件人}` / `{sender}`、`{主题}` / `{subject}`）。AI 起草的交代英文时用英文写、不知道的标 [TBD]。
- **更新卡片**：version.json 带 `notes: {en, zh}`（CI 跑 `release_json.py` 从 `up_notes` 取）；设置「关于」里有新版时摆出「Zhike 0.x 搞出来了 /
  这次弄了点啥 / 换版本不动你的设置、规则和 Excel」，照录入僧的定稿。0.3 的老程序不认 notes，照旧只显示版本号。
- **英文字体**：`html[lang=en]` 换一套西文在前的字体栈（Segoe UI Variable / Segoe UI 在雅黑前），中文不变。等宽数字只给计数、徽标、金额列、时间列，
  字段值、编号、日期不开（连字符会被撑宽）。表格里日期、编号、电话不再右对齐（只有金额、数量是「数」）。
- **长相**：提示条从深底改成跟顶栏一样的 98% 不透明（浅白 / 深 #1c1c1e）；表格比窗口宽时右缘渐隐不切半个字；字段值太长折行不切成「…」；
  路径太长省掉前头、留住文件名。英文界面按钮 1–3 个词，test_v04 和 shots-0.4.py 每屏查一遍：按钮没被撑破、没挤成两行、字没截断。
- **示例数据不沾佛门典故配买卖**：山门商贸 → 青禾商贸，Lotus Supplies → Bluepeak Supplies（示例、截图、测试里的假信）；比武材料（bench/samples、gen_mails）
  不给人看，没改，免得跟 0.3.0 的数字对不上。
- **介绍页**：同一页 EN / 中文，右上角切，记在浏览器（localStorage `zhike.lang`），网址带 `?lang=zh` 先听网址；`<html lang>`、`<title>`、description 跟着换；
