# 知客僧 · 微软登录（Outlook / Hotmail / Microsoft 365）怎么接上

代码已经写好（`app/zhike/oauth.py`，授权码 + PKCE，回调落在本机 `http://localhost:随机端口`，令牌只存用户电脑的凭据管理器）。
差一个「微软开发者应用」的 ID。这一步要用 Song 的微软账号做，Claude 不注册账号。大约 5 分钟，免费。

## 注册（Song 做）

1. 用浏览器打开 <https://entra.microsoft.com> ，用自己的微软账号登录（个人 outlook.com 账号也行）。
   第一次进可能要建一个免费的「目录（租户）」，照提示点就行。
2. 左边 **应用注册 (App registrations)** → **新注册 (New registration)**：
   - 名称：`知客僧`
   - 受支持的账户类型：选 **任何组织目录中的帐户和个人 Microsoft 帐户**（Accounts in any organizational directory and personal Microsoft accounts）
   - 重定向 URI：平台选 **公共客户端/本机（移动和桌面）**（Public client/native），填 `http://localhost`
   - 点 **注册**
3. 进刚建好的应用 → **身份验证 (Authentication)** → 最下面 **允许公共客户端流 (Allow public client flows)** 选 **是** → 保存。
4. **API 权限 (API permissions)** → **添加权限** → **我的组织使用的 API**，搜 `Office 365 Exchange Online`
   → **委托的权限** → 勾 `IMAP.AccessAsUser.All` 和 `SMTP.Send` → 添加。
   （`offline_access` 是 OpenID 自带的，不用单独加。不需要「授予管理员同意」，用户第一次登录时自己点同意。）
5. 回到应用 **概述 (Overview)**，复制 **应用程序(客户端) ID**（一串 `xxxxxxxx-xxxx-…`）。不要建「客户端密码」，用不上。

## 填进程序（Claude 或 Song 做）

- 把客户端 ID 填进 `zhike/app/zhike/oauth.py` 的 `CLIENT_ID = ""`，推到 main，CI 打出新 exe，老用户会自动更新到它。
- 介绍页 `zhike/index.html` 里两处「Outlook · 即将支持」「即将支持。微软不让用密码收信了…」改成正式说法。
- 程序界面不用改：`CLIENT_ID` 一有值，设置里输入 outlook/hotmail 地址就出现「用微软账号登录」按钮。

## 用户那头什么样

1. 设置 → 邮箱地址填 `xxx@outlook.com`（密码框自动藏起来）→ 点「用微软账号登录」。
2. 浏览器弹出微软自己的登录页 → 登录 → 点「接受」→ 页面说「登上了，回知客僧就行」。
3. 知客僧收信、转发、存草稿全走这个令牌，一小时一续，自动的。令牌失效（改了密码、撤了授权）时，那个邮箱显示「重新登录」。

## 坑

- 公司的 Microsoft 365：管理员可能关了 IMAP，或者不让员工自己同意第三方应用。前者报「这个邮箱没开 IMAP」，后者微软页面会说要管理员批准，让用户找 IT。
- 个人 outlook.com 默认开着 IMAP；关了的话：Outlook 网页 → 设置 → 邮件 → 转发和 IMAP。
- 测试：`tests/test_v02.py` 里有假的微软令牌服务器 + 假 IMAP/SMTP 的 XOAUTH2，整条路（登录 → 换令牌 → 收信 → 转发 → 续期 → 过期）不连微软也能跑。
