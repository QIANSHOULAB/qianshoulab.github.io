应用专用密码去哪拿
  • Gmail：先开两步验证，再到 myaccount.google.com/apppasswords 生成。
  • QQ 邮箱：网页版 → 设置 → 账号 → 开启 IMAP/SMTP 服务 → 生成授权码。
  • 163 / 126：网页版 → 设置 → POP3/SMTP/IMAP → 开启 IMAP → 拿授权码。
  • Outlook / Hotmail：微软在收紧应用密码登录，个人邮箱可能连不上，下一版接微软登录。
  • 公司邮箱：问管理员要 IMAP / SMTP 地址，程序里点「自己填服务器」。
