两步上岗

没有安装，没有注册。

  1. 下载，双击。Windows 要是拦一下，点「更多信息」→「仍要运行」。
  2. 连邮箱。填邮箱和应用专用密码（QQ、163 叫授权码），服务器贫僧自己认。贫僧拟好规则，你点「收下」。
GmailQQ 邮箱腾讯企业邮163126iCloudYahoo公司邮箱（IMAP）Outlook · 即将支持
应用专用密码去哪拿
  • Gmail：先开两步验证，再到 myaccount.google.com/apppasswords 生成。
  • QQ 邮箱：网页版 → 设置 → 账号 → 开启 IMAP/SMTP 服务 → 生成授权码。
  • 163 / 126：网页版 → 设置 → POP3/SMTP/IMAP → 开启 IMAP → 拿授权码。
  • Outlook / Hotmail / Microsoft 365：即将支持。微软不让用密码收信了，贫僧走微软登录，到时点一下登上就行。
  • 公司邮箱：问管理员要 IMAP / SMTP 地址，程序里填上。

贫僧嘴严

密码进 Windows 凭据管理器。邮件直接从你电脑连你的邮箱；AI 起草时，信直接发给你自己的 Google 钥匙，中间没有千手院。查新版只是读一个版本号。
