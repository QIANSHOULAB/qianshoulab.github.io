# 千手院设计规范（所有罗汉的界面照这个，2026-11-03 起）

Song 的要求：长相最差也要到苹果的水准（apple.com、macOS、iOS 设置页），只学苹果的长相，不学它的交互；交互照「最少操作」。产品质量线是业界收费工具。

## 总原则
- 一屏一件事，一个主按钮。能自动的事不出按钮。
- 克制：大量留白；颜色只用一个主色，其余全是灰。信息分层靠字号、字重、灰度，不靠框线和色块。
- 跟随系统浅色 / 深色，两套都要像样，不是把颜色取反了事。
- 八尊用同一套字、同一套间距、同一套控件，换的只有主色和图标。

## 颜色（直接抄这段 CSS 变量，主色换成本尊的）

```css
:root{
  --font:-apple-system,BlinkMacSystemFont,"SF Pro Text","SF Pro Display","PingFang SC","Hiragino Sans GB","Microsoft YaHei UI","Segoe UI Variable Text","Segoe UI",system-ui,sans-serif;
  --bg:#ffffff; --bg-group:#f5f5f7; --card:#ffffff; --card-2:#fbfbfd;
  --fg:#1d1d1f; --fg-2:#6e6e73; --fg-3:#86868b;
  --line:rgba(0,0,0,.08); --fill:rgba(120,120,128,.12); --fill-2:rgba(120,120,128,.2);
  --ok:#34c759; --warn:#ff9f0a; --bad:#ff3b30; --doubt:rgba(255,204,0,.22);
  --accent:#0071e3; --on-accent:#ffffff;   /* 换成本尊主色 */
  --r-card:18px; --r-btn:12px; --r-field:10px; --r-chip:8px;
  --shadow:0 1px 2px rgba(0,0,0,.04),0 8px 24px rgba(0,0,0,.06);
  --ease:cubic-bezier(.2,.8,.2,1); --t:240ms;
}
@media (prefers-color-scheme:dark){:root{
  --bg:#000000; --bg-group:#000000; --card:#1c1c1e; --card-2:#2c2c2e;
  --fg:#f5f5f7; --fg-2:#a1a1a6; --fg-3:#8e8e93;
  --line:rgba(255,255,255,.12); --fill:rgba(120,120,128,.24); --fill-2:rgba(120,120,128,.36);
  --ok:#30d158; --warn:#ffd60a; --bad:#ff453a; --shadow:none;
}}
```

- 主色从总舵首页那张卡的图标色系里取（qianshoulab.github.io「在岗罗汉」）：译经僧紫 #7B4DEB、抄经僧红 #E5484D、包租僧粉 #E2418C、化缘僧金 #D99A0B、巡山僧靛 #4E5BD6、代笔僧墨 #3A4150、知客僧赭 #C2552A、扫地僧橄榄 #6E9A24。主按钮上白字对比度不到 4.5:1 就把主色加深；深色模式主色提亮一档。
- 主色只用在：主按钮、选中、进度、链接。别处一律灰。
- 存疑标黄用 --doubt 底，不用红框。

## 字
- 只用系统字体（上面的 --font），不引 Google Fonts、不用 Inter/Roboto。数字一律 `font-variant-numeric:tabular-nums`。
- 字号阶梯（px）：首屏大标题 clamp(40px,6vw,64px)；页面标题 28–34；区块标题 22；小标题 17（600）；正文 17（手机）/ 15（电脑工具界面、插件）；辅助 13；注脚 12。正文不许小于 13。
- 字重只用 400、600、700。行高：标题 1.1–1.2，正文 1.5。英文大标题字距 -0.02em。
- 中文和英文、数字之间空一格；标点用全角。

## 形
- 圆角：卡片 18，按钮 12（大按钮 14），输入框 10，小标签 8。同类东西圆角必须一样。
- 间距只用 4 的倍数：8、12、16、24、32、48。区块之间 ≥ 32。手机左右留 16。
- 阴影只用 --shadow 那一档；深色模式不用阴影，靠 --card-2 抬起。
- 列表学 iOS 设置的分组列表：行高 ≥ 44，细分隔线从文字左边起，不到头。
- 能点的地方 ≥ 44×44。
- 顶栏、浮层用毛玻璃：半透明底 + `backdrop-filter:saturate(180%) blur(20px)`。
- 图标：线性、2px 笔画、圆头，像 SF Symbols。不用 emoji 当图标。本尊自己的图标跟总舵卡片统一（同色、同一个图形，可以精修细节）：网页当 favicon 和主屏图标，插件出 16/32/48/128 PNG，电脑程序当窗口和 exe 图标。

## 动
- 过渡 200–300ms，用 --ease；不弹跳、不闪、不转圈转个没完。
- 超过 1 秒的活要有进度：知道多少用细进度条，不知道用小转圈加一句在干啥。做完给一个轻的完成动效。
- 尊重 `prefers-reduced-motion`。

## 控件
- 系统默认的 select、checkbox、radio、file input 不许裸露，统一重画：开关用 iOS 式开关，二选一、三选一用分段控件。
- 主按钮：主色实底白字，高 44（电脑和插件可 36），一屏最多一个。次按钮：灰底或纯文字。
- 拖放：整页（整窗）都能丢，拖进来整页高亮，不是只有一个小框能丢。
- 空状态：一句话 + 「用示例试试」，一点就跑出结果。
- 出错：一句人话 + 怎么办，放在出事的地方。不许用 alert / confirm；危险操作给「撤销」，不问「确定吗」。

## 布局
- 网页：内容最宽 980（工具区可到 1120），居中；手机 390 宽单列，没有横向滚动。首屏一句大标题、一句副标题、主操作，不放说明书。
- 插件侧栏 / 弹窗：宽 360–400；顶部名字 + 状态，中间只干一件事，主按钮在底部。
- 电脑程序：窗口 ≥ 1100×720；左边栏 220 宽（分组列表），右边内容；标题栏干净，不堆按钮。

## 别这样（一眼就露馅的「AI 味」）
满屏渐变和紫色；卡片套卡片；每行都加粗；大段居中的字；粗边框；五六种颜色；灰字配灰底看不清；emoji 当图标；全大写小标签；12px 正文；默认样式的下拉框和复选框；各处圆角不一样；字挤在一起；说明书一样的长段落；按钮上写一句话。
