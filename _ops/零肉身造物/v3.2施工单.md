## 要做的

### 1. 首屏：只有门

- v3.1 之后首屏是：门、wordmark、往下滑的小提示。这张单不往首屏加任何名字、任何线。
- 检查 v3.1 有没有漏拿的：五个名字、引线、鼠标移到门上那五撮石头时的高亮和点击、读屏里那五条链接。漏了就拿干净。门上不留暗门。
- 顶栏多两个字：**目录**（英文 INDEX）。字体字号跟「声音：关」一个样。首页顶栏现在左边 EN / 中文、右边声音、中间空着，建议放正中，保持左右对称。点得到的范围不小于 44×44。七幕全程都在。

### 2. 「目录」：快进到造完的那片天

- 点一下：世界从现在的进度快进到结尾「开天」。从头到尾约 2.5–3 秒，离得近就短些（不短于 0.8 秒），起步和收尾都缓。快进时每一幕的名字和「进去」先收起来，别一串字闪过去。
- 快进完，页面的滚动位置就在结尾：往上滑照样倒放。结束那一下不许跳、不许闪。
- 快进途中用户一动（滑、点、滚轮、按键），马上把控制权还给他，不跟手指抢。
- 开场那段还没走完就点了「目录」：开场先快进完（现成的），接着快进到天上，一口气。
- 已经在天上再点：不动地方，五个名字轻轻亮一下。
- 减少动效（prefers-reduced-motion）：不快进，直接到结尾。没有 WebGL：滚到结尾那段静态图和文字列表。

### 3. 天上的五个名字

- 「开天」落定以后（进度大约 6.8 往后），五样造物旁边各亮起自己的名字，照造出来的先后一个个亮：
  太阳 → 千手院｜星环 → 赛博杂货铺｜巨鲸 → 标本｜浑天仪 → 文物｜轨道 → 法典。
- 只写名字（英文 QIANSHOU LAB / CYBER BODEGA / SPECIMENS / ARTIFACTS / CODEX）。不写编号、不写口号、不写别的。字体跟每幕的栏目名一路，小一号。
- 名字要「长」在它那样东西上，一眼看得出谁是谁的。贴着放最好；贴不上的（轨道满天都是）可以拉一根很短的细线，线那头必须是那样东西本身。造物在转、镜头在动，名字跟着走。
- 字压得住：星云很亮，名字底下垫一小团暗，白字，任何时候都读得清。颜色只留给造物自己的光，名字不染色。
- 点名字，或者点那样造物本身：马上冲进去（现成的那套：镜头扎进这样造物、满屏它的颜色、栏目页从这个颜色里淡出来）。手机上点一下就进，不要「先点亮、再点进」两下。
- 电脑上鼠标移到名字或造物上：造物亮一点、名字亮一点、鼠标变手。Tab 键按 千手院 → 法典 的顺序走五个名字，回车进，焦点看得见。读屏：一个叫「目录」的导航，五条链接。
- 往回滑离开结尾：名字先暗下去，造物再照 v3.1 的样子飞回去。
- v3.1 在结尾底下排的那一行五个栏目名：有了天上的名字就不要了，一个名字别出现两回。那句「把折磨肉体的活交给代码，把肉身还给生活。」和页脚照旧。没有 WebGL、没开 JS 的时候，那一行文字列表留着当兜底。

### 4. 点了要有反应（Song：「点了以后好像啥都没有」）

- 用 WebKit、开触摸（Playwright 的 iPhone 机型，用 `tap`，不是 `click()`）真点一遍：「目录」；天上五个名字各一次，每次都落到对的网址；第二到第六幕的「进去」各一次。有一个点了没反应、或者要点两下，就是没做完。
- 从天上点进栏目页，再按浏览器的后退：回到的是那片天，五个名字还在、还能点。不是黑屏，不是卡在满屏颜色里，不是回到开头。

### 5. 黑不是纯黑（Song 09:01：「一开始的黑也不是纯黑，是某种颜色的深色但接近黑色。」）

- 整个首页的画面里不再有纯黑 `#000`。天、水、暗角、页面底色用同一个「接近黑的深色」，这个世界的暗只有这一种颜色，从开场一直用到结尾；每一幕的光照旧叠在它上面。
- 色相：**墨蓝**（黎明前的夜、深海）。底子是冷的，第一样造出来的太阳是暖的，冷底上第一点暖光。（Song 09:13 在三个色相里选的 A 墨蓝；另外两个墨紫、墨褐不用。）
- 多深：第一眼以为是黑，跟纯黑并排才看得出颜色。参考值：天 `#06080F` 上下，水比天再暗一点，亮度别超过 `#0A0C14` 这一档；饱和度往低里收，不要做成「深蓝色科技风」。数值集中放在 `tune.ts`，照截图调。
- 门要比底色更暗，开场光还没出来的时候，门是暗里更暗的一块，轮廓读得出来。
- 接近黑的渐变最容易出色带：现成的抖动和胶片颗粒要盖得住，1440 和 390 的截图放大看，天上不许有一圈一圈的台阶。
- 页面底色跟着换：WebGL 没起来之前的那一屏、`--bg`、`<meta name="theme-color">`（iPhone 的 Safari 顶上底下两条跟着这个颜色走）、没有 WebGL 时的七张静态图（重新拍）。四个栏目页的底色用同一个变量，从首页冲进去以后底色对得上。`/qianshou/` 不碰。
