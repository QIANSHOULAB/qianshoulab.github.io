# 案例：照片认字成表（录入僧）

一句话：一叠手写或打印的单子拍照，认出来填进固定格式的 Excel，人只核对。电脑版在 `QIANSHOULAB/bangong`（设计记录 `docs/设计记录.md`，网盘「产品设计记录」里也有一份），网页版在总舵 `luruseng/`。

## 跑通的做法（10-29 设计记录里的清单，做同类先照这个）
- 先定输出：拿真表格和要填进去的目标表，把列定死，再动手认。
- 先查额度：按请求还是按字算、每天上限、几点重置。
- 准第一：一张照片一次请求，不打包（11-23 又试过打包 3–5 张，省不了多少时间，不做）。
- 编号：表里第几行、照片上写第几号（写在照片空白处），人一眼对得上。
- 只标两种红：模型自己说拿不准的，加上硬规矩查得出来的（合计、日期读不成日期、公司名单里没有的人号机号）。认得确定的就算以前没见过也不标。
- 学习只认人核过的：「投喂数据」把公司核过的老表喂进去当准绳；从不拿自己认出来的结果当真。
- 报错原样给人看。
- 钥匙、同事和公司的数据只放用户电脑，不进公开仓库。
- 每条出错的路都拿假服务器测一遍。
- Windows 程序走 GitHub Actions 出 exe，带冒烟测试（见 `发版.md`）。
- 核对窗口：从第 1 张开始，左右翻，输号直跳；在核对里改了，Excel 那格跟着改。
- 核完两条路：下载；或者接着公司表最后一行，按编号顺序自动填进去，不带任何标记。

## 手机拍、电脑认
- 电脑网页上出二维码，手机一扫就成了传图通道，拍完一传，照片加密经 Cloudflare 转到电脑（`信箱.md` 的 `/r`）。
- 11-22 起认字先交给大管家（Opus，经信箱），大管家不在才用 Gemini（Song 试过 Gemini，「一团糟」）；给别人用的，配对时输一个暗号，不是谁打开网页都能叫大管家。提速只做了两件：照片先缩小，电脑和掌机一起认。

## 苹果本机认字（122 照妖镜，铁屑江湖 iPhone 0.2.0）
- iPhone app 里认印刷体表格，用苹果自己的 Vision（`VNRecognizeTextRequest`，accurate，英文 + 简体中文）就够：不用下模型、照片不出手机、不花额度。8 张假检查表（歪、倒、横、透视 + 模糊 + 阴影、毫米表、没表头）跟网页版（PaddleOCR）比，353 格全对上。
- 扶正别靠 Vision 的字框四角（透视、模糊时量错）：先用投影法量歪（缩到 800 宽，比周围暗一截的算墨、阴影不算，试一圈角度取横向投影最尖的），转平以后让 Vision 四个方向各看一眼（fast）挑认得最多的。
- Vision 跟 PaddleOCR 的三处不同要补：一次全认（要只留要的列）；中英混的表头会认成一串（「STOCK 余量」→「STOCK FE」，要拆）；偶尔整个词认成乱码（「DIMENSION 尺寸」→「DIENRJ」，按左右位置补）。
- 认得准不准，拿网页版当标准答案最省事：Playwright 把同一张图喂给网页版、抄下每一格，app 的单测逐格比；Vision 在 CI 的 iPhone 模拟器里能跑（`usesCPUOnly`）。测试结果靠 `XCTFail` 的消息从 GitHub 注释里读（不登录也能读）。

## 什么时候用
- 任何「拍照 → 认字 → 进表格 / 进系统」的东西：先抄上面那张清单，再看表格长什么样。
