# 案例：网页小工具（千手院那些罗汉）

## 怎么搭
- 单文件页面，放总舵一个文件夹，推上 main 就上线（见 `发版.md`）。
- 免费、不注册、数据不出用户电脑：表格、照片都在浏览器里处理，不往别处存。
- 要用 AI 的：用户贴自己的谷歌钥匙（「钥匙 1」，「钥匙 2」当备胎，1 号用完自动换 2 号），配一页领钥匙教程（录入僧的 `key.html`：四步、三条铁律，口气照 `topics/product-copy-style`）。不想要用户领钥匙的，走 Cloudflare 免钥匙通道，站里用 Song 的钥匙、按 IP 和总数限额（`信箱.md` 的 `/count`）。
- 手机拍、电脑处理：网页出二维码配对，照片经加密中转站过来（`信箱.md` 的 `/r`）。
- 默认英文、第二中文；英文重写不翻译。按钮照直写，别的字不一本正经、不写免责。
- 每个工具都有「提意见」：点了开一封邮件，标题带「[千手院反馈]」+ 工具名 + 版本；每周日意见箱定时任务收、判采纳 / 先放着 / 不管，发给 Song。
- 长相：苹果是下限；交互照最少操作，只去掉没必要的步骤。

## 什么时候用
- 给别人用、不想让人装东西的小工具。要常驻、要碰本机文件或者装不上网页做不了的，做 Windows 程序（`发版.md`）。
