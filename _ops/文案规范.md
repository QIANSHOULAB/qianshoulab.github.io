## 中英两套
- 每尊的界面文字集中放一处（strings 文件），中文、英文各一套。跟着浏览器 / 系统语言自己切（网页和插件看 navigator.language，电脑程序看 Windows 显示语言），不让人选；设置里留一个切换，给想换的人。
- 英文不是翻译，是重写：照英文用户的习惯从头写，读着要像英文母语的产品团队写的。
- 名字：中文照旧（译经僧、抄经僧……）。英文用「拼音 · 一句大白话说干啥」，八尊统一这个格式，比如 Saodi · File Sweeper、Daibi · Form Filler；不直译成 Translation Monk 这类。
- 梗只用这门语言自己文化里活着的：
  - 中文：千手院的寺院腔（施主、贫僧、超度、化缘、开光）、打工人、摸鱼、牛马、修仙这类。
  - 英文：英文科技产品那种干冷幽默、轻描淡写、自嘲；英文读者一看就懂的禅意词（zen、monk mode、enlightenment、inner peace）。不硬翻「施主」「贫僧」「超度」——读者看不懂的梗等于没有梗。
- 自然：读出声不别扭。不要翻译腔——中文别写「进行……操作」「您的……已被成功……」「请点击……按钮」；英文别写 Please kindly、Operation succeeded、Click here to。
- 字少：每屏说明能删就删，一句能说清不写两句。按钮中文 1–4 个字、英文 1–3 个词，照直写（下载、开始盯；Download、Start watching）。
- 免责声明、「仅供参考」「请自行核对」「本工具不对……负责」「使用前请仔细阅读」，中英文一律不写。真要提醒的（比如数据不出你的电脑）写一句，放在用得着它的地方。
- 吹牛里的数字只能取自比武 / 复赛实测。
