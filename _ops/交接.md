## 八、踩过的坑

- orders 用默认 `git fetch` 拉不到新单（只拉 main），看起来像单子没推上去。
- 提交时间有的是 UTC、有的是新加坡时间，算「多久没动静」前先对时区。
- 别人家仓库的 `gh api .../contents` 会被会话代理拦。要看源码用 `git clone --depth 1 --filter=blob:none --sparse`，或者 `gh api search/code`。
- GitHub Pages 有约 10 分钟缓存，刚推的网页不一定马上变。
- 一叶笺目前没有「大管家往手机送一条普通便签」的路（「送来」只认带录音的听力稿）。要给 Song 递一串东西，走看门狗的 Telegram。
