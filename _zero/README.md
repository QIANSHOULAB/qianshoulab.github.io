## v3.3（停手以后自己走到展示位置；星尘字）

- **展示位置一处说了算**：`tune.ts` 的 `REST_PS`（首屏 1、第二到第六幕 k − 0.12、「开天」7）。刻度、「目录」、天上名字、Tab、键盘、后退回来、停手以后都认它。
- **停手以后自己走**（`src/home/glide.ts`，数在 `tune.ts` 的 `SETTLE`）：手指离开且惯性停了（140 毫秒没再滚；浏览器报了 `scrollend` 就再等 70 毫秒）、滚轮 / 触控板 200 毫秒没有新的——就按方向走到最近的展示位置：往前滑去前面那个；只冲过一个、冲过头不到 0.25 屏退回那个；离起点不到 0.05 屏的小抖动回原位。门槛按屏数算。走多久按距离开方：一整幕 1.2 秒，「开天」那一段按 2.8 倍距离算（约 2 秒），最短 0.38、最长 2.6 秒，缓动 cubic-bezier(.42, 0, .22, 1)。逐帧 `scrollTo`（不用原生 smooth、不用 scroll-snap），每帧按当时的屏高从进度换算滚动位置，落定以后记住进度、改窗口大小也钉在那儿。一有新输入（手指按下、滚轮、方向键、空格、PageDown）马上停。触控板惯性：一串递减的小 delta 不算新输入，也不在它没完的时候接管。自己滚出来的 scroll 不算用户输入。键盘 ↓ / 空格 / PageDown 下一幕，↑ / PageUp 上一幕，Home / End 首屏 / 开天。减少动效：直接落到展示位置。「目录」快进也是这套（`kind = 'index'`，时长照旧按 `INDEX`）。
- **「进去」一口气**：点了以后镜头扎进去、满屏颜色、落到栏目页；途中滑、点、滚轮都不理；栏目页慢就停在满屏颜色上等。后退回来直接落在离开时那一幕的展示位置。
- **星尘字**（`src/scene/stardust.ts` 碎块和清楚的字、`words.ts` 摆在哪、`sdf.ts` 字的距离场；数在 `tune.ts` 的 `DUST`）：栏目名（第二到第六幕）、那句话、天上五个名字、退路 B 的列表，都在 3D 里由碎块聚成——栏目名和天上的名字从各自那样造物身上掉下来（太阳金、星环粉、鲸、浑天仪、轨道），那句话由门炸开升天的星（每 5 颗里 2 颗）聚成。聚到哪跟着进度走：一幕从这一段的 50% 开始聚、到展示位置聚好；倒着滑散回去。聚好以后是清楚的细发光字（距离场在屏幕原生分辨率画，按场景深度遮挡，水里有倒影），边上留 3.5% 的光点慢慢飘。首屏 wordmark 不飞不聚，跟门一样在暗里，光升起来才照出来。换语言约 0.6 秒散开再聚。减少动效：直接是聚好的字。真字照旧在 DOM 里（透明、跟 3D 那份对齐），读屏、Tab、搜索、翻译靠它。
- **字体**：全站细黑，没有宋体（见 `scripts/fonts/README.md`）。Montserrat 200/300 + 思源黑体 200/300，自托管、只留用到的字。
- **天上名字贴着自己那样造物**：候选落点在造物外沿上（太阳、浑天仪一圈 16 个点，星环沿屏幕上那圈点，鲸沿身子两边各 13 个点），离上一帧越远越不划算，真换地方 0.25 秒滑过去；点在名字 0.3 秒内待过的地方也算点中。
- 新的调试参数：`?dpr=0.5` 画面分辨率定死（验收脚本在没显卡的机器上压低它，量手感才准）。`window.__zero` 多了 `to(P, kind)`、`glide()`、`gliding()`、`dust()`。
- 验收：`scripts/v33-test.mjs`（停手、甩、刻度 / 目录、滚轮、触控板惯性、键盘、进去 + 后退、帧数、录屏）、`scripts/v33-shots.mjs` + `v33-sheet.py`（每个展示位置 390、1440 中英各一张，半路两张，查字体；总览图、录屏转 gif）。工作流 `zero.yml`：推分支 `zero-v3-3` 只跑预览。

## 第二版长什么样（Song 11-27 定的）
- 只有黑、白、灰；简单几何，做工要拿得出手。对标 Igloo Inc（方块拼成的主体、等宽小字带细引线）。
- 首页：一望无际的黑水，地平线正中一块 1:4:9 的碑，324 块黑石（InstancedMesh）砌成。开场几乎全黑，10 秒里光从碑后面慢慢升起来（天从黑变成白灰、碑成剪影带一圈细亮边、碑缝透光、光芒从边上散开、水上一条光路铺到脚下），然后极轻地呼吸。同一次会话再来、或者点一下 / 滑一下 / 按个键，1.5 秒快进到天亮；系统设了「减少动效」就直接给天亮的样子。
- 全集和子集：碑是全集，下半截五撮砖是五个子集（01 千手院、02 赛博杂货铺、03 标本、04 文物、05 法典）。平时看不出来；指到铭文或者那撮砖，那撮就沉沉地从碑里出来，背后的光从新开的口子里涌出来，缝发亮，铭文一个字一个字写出来。点了（回车、手机上第二下）镜头贴着水面冲进那道光，白光吞屏，然后跳转。
- 声音默认关，右上角 SOUND: OFF，记住开没开。开了只有三样：随天亮升起的低长音、出碑时一声石头闷响、进门时一口气涌上来的光声。全是 Web Audio 当场合成。
- 没有 WebGL：换成一张天亮时的静态图（`src/assets/still-*.jpg`，自己的场景截的）+ 文字链接。

## 写一篇新标本（写完推上去就上线）
1. 在 `src/content/specimens/` 放两份：`002-名字.en.mdx`、`002-名字.zh.mdx`（英文重写，不是翻译）。
2. 头上照 `001-cinderfall-arena.zh.mdx` 那样写：id、lang、slug、title、date、species、scale、liveUrl、sourceUrl、sourceLabel、modelStack、summary。
3. 两份的 id、date、链接、modelStack 必须一样，不一样构建报错。
4. 推到 main：工作流 `.github/workflows/zero.yml` 自己构建、把产物提交到根目录（不碰根目录 index.html），GitHub Pages 发出去，再对着真网址验一遍。

## 本地
```
cd _zero
npm ci
npm run build              # 出到 _zero/dist
node scripts/publish.mjs   # 拷到仓库根目录（只动 zero、zahuopu、zhahuopu、specimens、artifacts、codex、zero-assets）
```
平时不用本地拷：推上去工作流会做。`publish.mjs` 发现 dist 里有名单外的东西会直接停，不会踩到别人的网址。

调试用的网址参数（只影响自己这一次）：`?dawn=0.5` 把黎明定在一半；`?still` 只留画面（截静态图用）；`?hq` 不自动降分辨率；`?lang=zh` 中文。
