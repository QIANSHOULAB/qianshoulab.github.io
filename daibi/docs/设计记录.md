# 代笔僧 · 设计记录（给以后接手的 Claude）

代笔僧 = 千手院的自动填表插件：Excel/CSV 一行一行填进别人家网站的表单。对标 Bardeen、Axiom.ai。
介绍页 https://qianshoulab.github.io/daibi/ ，插件包 `daibi/dist/daibi-0.3.0.zip`（当前 0.3.0）。示例表单 https://qianshoulab.github.io/daibi/demo/ （侧栏「用示例试试」打开它）。

## 填表引擎（panel.js）

- 每个网站（origin）一份对应：`maps[origin] = {b:{表头:{sel,label,kind,conf}}, btn, start}`，存 `daibi:maps`；表和每行状态存 `daibi:sheet`。
- 一行的生命周期：`startRow` → `fillStep`（填当前页上还没碰过的已绑字段，记进 `run.seen`）→ 手动模式等用户点提交 / 自动模式 `submitNow` → 
  - 页面跳了（tabs.onUpdated complete）→ `onPage`：页上有没碰过的绑定字段 = 多页表单下一页，接着填；没有 = 这行交了 → `rowDone`。
  - 页面没跳（Ajax）→ `checkAfter` 轮询：已填的文本框一半以上清空 = 交了。
  - 表单回来了但值还在 = 没交上 → 标出错（原因取 validationMessage）。
- `rowDone`：页上又是空表单 → 直接填下一行（手动模式也填，用户只管点提交）；是成功页 → 自动模式跳回 `start` 网址，手动模式主按钮变「回表单，填第 N 行」。
- 多页表单第 2 页的字段，在跑的时候自动补对应（只收 score≥0.75 的），见 `addNewMatches`。
- 出错：自动模式标红后跳回表单页接着下一行；手动模式停下。「重试出错的」把出错行改回待填重跑。
- 验证码（recaptcha/hcaptcha/turnstile/geetest/名字带 captcha/验证码 的框）：填完不提交，标「卡在验证码」，等人自己点提交后继续。

## 去掉没必要的步骤（0.3.0）

步骤账见 bench/比武报告.md「0.3.0 复赛」（`bench/steps.js` 照真人做法走，0.2.2 和 0.3.0 各走一遍）。默认还是手动模式：提交由人点（拍板 2A）。

- **答应过的网站，表一放就填第 1 行**（`autoFill`）：手动模式 + 表在 + 字段对上 + `permissions.contains` 这个网站 + 当前页就是当初对字段的那一页（`onStartPage`，同站别的页碰巧有同名框不填）+ 这一行待填 → 自己 `startRow`。
  触发点：放表（setTable）、对完字段（startMatch）、点选完（pickFor）、页面刷新/切标签（refreshPage）、侧栏打开。
  有框没主、表里又有带数据没对上的列 → 不填，先出黄条问（跟 0.2.x 点「填」时问的一样，只是提前了）。
  第一次进某网站还没答应 → 不自己填，留主按钮那一下：浏览器只在侧栏里有人点的时候才肯弹「允许吗」，这一下就是答应。
  填完提示条「第 N 行填好了，看一眼，点网页上的提交」+「撤」：`undoFill` 刷新网页回空表、这行退回待填、`run.hold=true` 不再自己填，等人点主按钮。
- **成功页自己回表单**：0.2.x 手动模式交完落到成功页，主按钮变「回表单，填第 N 行」要人点；0.3.0 两种模式都自己 `tabs.update(m.start)` 回去填下一行，提示条「第 N 行交了，回表单填第 N+1 行」+「停」（`stopHere`：不再自己填）。
- **同一张表又放进来，交过的行记着**（`carryOver`）：同名 + 同表头 + 同一个网站（`S.site` = 最后交成功的网站）→ 内容一样的行保留「完成」，从第一行没交的接着；提示条「从头来」（`fromTop`）。换了网站不算（交到 A 站不等于交到 B 站）。0.2.x 一律清零，人得自己找到第 13 行点上，不然前 12 行再交一遍。
- 同一网站第二次不再对字段：0.2.x 已经按网站记住了（`maps[origin]`），步骤账实测第二次没有对字段这一步，不用改。
- 并发：自动填的那一行可能还在填，人就点了「连填」/「从头来」。`startRow` 每次 `run.gen++`，旧链醒来发现号变了就收手；`settled()` 等 `run.active`（startRow 链）和 `run.fillBusy`（fillStep）都停了再开跑。填到一半网页换了（人刷新、点走）→ 在新页上把这一行重填（`run.navFill` 连续 3 次就标出错「填着填着网页自己跳走了」），不当成交了。
- 主按钮：没表 =「选文件」；只剩出错的 =「重试出错的 N 行」；全交完 =「再放一张表」；正在填/回表单/看交上没 = 灰的「稍等，贫僧在填」（防止人再点一下两头抢一张表）；手动模式等人提交 = 灰的「重填第 N 行」。
- 空状态「用示例试试」：读 `sample.csv`，开新标签页到示例表单（测试里 FIXED_TAB 就在原标签页），页面到了再 setTable → 自动对字段 → 自动填第 1 行。manifest 加了 `host_permissions: https://qianshoulab.github.io/*`，示例不用再弹授权。

## 下拉 / iframe / 日历 / 弹框 / 千分位（0.2.1）

- **跟网页说话的通道**改了：不再用 tabs.sendMessage，改成 `scripting.executeScript({allFrames:true, func: m => window.__daibiDo(m)})`，一次问遍顶层和 iframe，每个 frame 的答案带 frameId，侧栏 `call()` 按消息类型合起来（scan 拼字段、fill 每格取认领它的 frame、submit 取 mine 的那个）。缺手的 frame 先注 page.js+content.js 再问。
- **iframe**：iframe 里的选择器加前缀 `@来源|css`（如 `@https://form.x.com|#name`），顶层原样（老的对应不用迁）。每个 frame 只认自己前缀的。点选 `pickAny`：每个 frame 各等一次点击，先点中的算，其他取消；提示条只在顶层出。
  授权：顶层 scan 顺带报页里看得见的 iframe 来源，`askAccess` 一次要「本站 + iframe 的站」。没授权的 iframe executeScript 自动跳过，不炸。
- **自定义下拉**（kind `combo`）：认 `role=combobox` / `aria-haspopup=listbox` 的非原生元素和 AntD/Element/MUI/select2/vue-select 等外壳（取最外层），里面的输入框都算到它头上。选项从子树、aria-controls/owns、或展开后 body 下的 `[role=option]` 等弹层里找。
  填：先发 mousedown（AntD/MUI 按下就开）→ 没开再 click（Element/自家组件）→ 再不行 ArrowDown；按文字点中选项，看外壳文字变了算成；没有这个选项 → 关上，这行标「选项里没有」。能搜的下拉先打字再找。
  0.2.2 起在真 AntD / Element Plus / MUI / select2 上实测，见下一节。
- **日历控件**（kind `datetext`）：只读框且 label/placeholder/name/class 像日期，或可写但 placeholder/name/class 像日期。按框的格式写：placeholder 写了 YYYY/MM/DD 照它，写了样例日期照样例，否则 YYYY-MM-DD；原生 setter + input/change + Escape。可写框遇到看不懂的值原样写，只读框才报错。
- **弹框说人话**：提交前侧栏往网页自己的世界（world MAIN）装 alert 钩子；content 点提交前在 `<html>` 上挂 `data-daibi-arm`，4 秒内的 alert 不弹，话记到 `data-daibi-alert`，提交回话/之后轮询都会带回来 → 这行立刻标「网页弹框不收：「…」」。平时（手动模式用户自己点）alert 照常弹。confirm 不碰。
- **千分位**：整列都是数且至少一格带千分位的列（`isNumCol`），填进文本框时去逗号；`inputmode=numeric/decimal` 的框也去。
- **开跑前提醒**：点「连填/填第 N 行」时，网页上还有没主的框（上传框、验证码除外）、表里又有带数据没对上的列 → 底栏上方黄条「网页上「产品版本」还没对上表里的列，照填就空着交」+「照填」「去点选」（去点选：用 match.score 给这个框挑最像的列，直接进点选）。照填后这些框记进 `maps[origin].skipF`，同网站不再问。说框不说列：这页本来就没有的列很常见，列出来全是噪音。
- 用户亲手解绑的列记进 `maps[origin].off`，跑的时候「多页表单自动补对应」不再把它补回去（0.2.0 的 bug：解绑了跑起来又自己绑回去）；「重新对」清空。
- 底部栏高度用 ResizeObserver 写进 `--dock-h`，页面留底；提示条挪到侧栏顶上（压招牌不压数据）。
- 验证码控件自己的勾（.g-recaptcha 等里面的 input）不算可填字段。

## 真组件库 / 日历格子 / Shadow DOM（0.2.2）

- 实测台：`bench/real/` 用 npm 官方源装 antd 5.29.3、element-plus 2.14.7、@mui/material 9.5.0 + @mui/x-date-pickers 9.17.0、select2 4.0.13（jquery 3.7.1），esbuild 打成 5 个页（`node build.js` → `build/`，node_modules 和 build 不进仓库），`bench/site.js` 的 +9…+13 端口出页。
- **下拉**：
  - 选项「真看得见」才算（`page.shown`：有面积、没藏、不透明度不为 0）。AntD 给读屏另放一份 0 宽的 `role=option`（字是 value），以前会点到它上面。
  - 点开前记下已经看得见的选项（上一个下拉正在收起的菜单）当 `stale`，不算这个下拉的。
  - 单选点中后等 `aria-expanded=false`（不等收起动画）；没收就 Escape。
  - 虚拟列表（AntD 默认只画看得见的几条）：找不到就把弹层滚着找（`scrollFind`）。
  - 能搜的下拉：打字搜不到要把搜索词清掉，不然列表留成空的，后面的选项全找不到。
  - **多选**：整格先当一个选项找，只认「完全一样」；不一样又能按 `、，,；;|/` 拆成几个 → 逐个点开点中，不要的勾掉，最后核对每个都在外壳上显示。整格模糊匹配会把「需发票, 海外」配成「需发票」，所以多值格不吃模糊匹配。
  - select2 / Chosen：原生 select 藏在旁边（`select2-hidden-accessible`、`aria-hidden=true`），直接填原生的再发 change，它们都听；皮不单独算字段。点选点到皮上也绑到原生 select。
- **日历控件**（`fillDateText`）：
  1. 能打字的框：照框的格式写 + input/change + 回车，失焦后等一轮重画，框里还是那天才算（Element Plus 走这条）。
  2. 分段日期框（MUI X v8+ 的 `role=group` + 几个 `spinbutton`，React Aria DateField 同款）整个算一个字段；先往它藏着的 input 写整串（`MM/DD/YYYY`，照框里写的格式）。
  3. 只读框 / 写了不认（AntD `inputReadOnly`、自建日历）：**点开日历 → 翻到那个月 → 点那一格**。弹层 = 点开后新冒出来的 1–31 日子格的公共祖先，再往上到不含输入框的最外层；月份从标题读（`2026年11月` / `November 2026` / `2026-11`），读不出就看格子上的 `title / aria-label / data-date / data-timestamp`；翻页钮认 aria-label/title/class/‹›；差 12 个月以上先按年翻。格子上有日期属性就按属性点，没有就排除「上月/下月」格（class 带 prev-month/outside 之类）按字点。有「确定」钮就点。
  4. 都不行才像 0.2.1 那样硬写 value。
  验证都看「框里现在显示的是不是那天」（`shownDate`），不看我们写进去的字。
- **Shadow DOM**：`page.allRoots()` 递归所有 open shadowRoot；里面的元素选择器写成 `宿主 >>> 里面`（可多层，如 `qs-signup >>> #phone >>> label > input`），`find` 一层层钻。label/aria-labelledby 在元素自己的 root 里找。事件都带 `composed:true`。点选、「用户自己点了提交」用 `composedPath()[0]`。closed shadowRoot 进不去（浏览器不让）。
- **选择器更稳**：组件外壳优先 `tag.类:has(#里面输入框的稳定id)`；路径里每一级优先「同类兄弟里第几个」`div.MuiFormControl-root:nth-child(2 of div.MuiFormControl-root)`，前面插进「已保存」提示条不错位（0.2.1 的 nth-of-type 在 MUI 页上整排错位，城市值写进产品框）。组件库每次刷新都变的 id（`:r7:`、`el-id-…`、`mui-…`、`rc_…`）不用。
- **按名字自愈**：侧栏把绑定时的 label 一起发过去；选择器找到的框名字对不上，就按名字在这页重找，唯一才用。
- AntD 按钮字中间塞空格（「提 交」），认提交钮前去掉。

## 上传框和表格链接（0.2.0）

- 上传框：单元格写文件名（多个用 ；、，| 隔开，带路径也行，只看文件名），文件放进侧栏的「附件」（拖进侧栏或点「放附件」）。
  填的时候从 IndexedDB 取出，base64 传给网页，用 DataTransfer 塞进 input.files，再发 input/change。缺文件 → 这行标出错「附件里没有…」，补上后重试。
  藏起来的上传框（display:none，外面包一个「选择文件」按钮）也算可见；label 是「选择文件/上传/浏览」这类按钮字时，改取旁边的文字当名字。
  「附件」一栏只在页面有上传框、或已有附件、或绑了上传框时才出现。
- 表格链接：「粘贴」框里贴链接，或在侧栏空白处直接 Ctrl+V 链接。Google 表格链接换成导出 CSV 地址（发布到网页的 /d/e/… 换成 pub?output=csv），带 gid 就读那一页。
  先在点击里同步要 docs.google.com + *.googleusercontent.com 的权限，再 fetch（credentials: include，所以私有表只要浏览器登录了 Google 就能读）。拿回 HTML = 跳登录页了 → 提示设成「知道链接的人可查看」。
  「刷新」重读：内容没变的行保留状态，新增的行待填。
- 沙盒连不上 Google，Google 链接只测了地址转换和本地模拟链接，真表没测过。

## 权限设计

- 装的时候不要任何网站权限（商店审核友好）。点工具栏图标打开侧栏会给 activeTab。
- 第一次在某网站点「对字段」/「点选」/「填」，在点击里同步调 `chrome.permissions.request({origins:['https://域名/*']})`，用户允许一次，以后这个网站跨页、刷新都能用。
- 匹配模式不能带端口：`http://127.0.0.1/*` 覆盖所有端口（setUrl 里生成 tab.pat）。

## 踩过的坑

- Playwright 的 `setInputFiles(路径)` 碰到中文文件名，node 进程直接静默退出、不报错。改传 `{name, mimeType, buffer}`。
- 装了扩展的 Chromium 不能用默认 headless，要 `headless:false` + `xvfb-run`。
- 导航进行中对后台标签页截图会卡 30 秒超时；要截跑动中的画面，先截侧栏、暂停后再截网页。
- 侧栏里 `chrome.permissions.request` 必须在点击处理函数里同步调用，前面不能 await 别的，否则丢了用户手势不弹窗。
- executeScript 的 func 返回 Promise 会等它；返回里的 undefined 会变 null，所以「不归我」用哨兵 `\u0001` 不用 undefined。
- 提交时 content 是同步点按钮再回话（为了当场读到 alert）；页面跳走、回话丢了就当交了，看跳到哪。
- 填值要走原生 value setter + input/change 事件，React/Vue 受控组件才认（测试站的 Ajax 页专门测这个）；最后 `el.blur()`，不然日期框留着焦点高亮。
- 复选/单选用 `el.click()` 真点，网站自己的监听才会触发。
- 结果列表滚到当前行要给 `.rlist` 加 `position:relative`，不然 offsetTop 算错。
- 表头「开发票」对「需要发票」这类说法差太远的，自动配不上，故意留给用户点选，不硬猜。
